# 示例提示词

六条按当前方法手写的完整提示词，用来对照「写到这个程度算不算够」。**多数没有成片验证**，不是成功案例；其中 05、06 已用生成结果回查过稿子。

| 文件 | 题材 | 它主要考什么 |
| --- | --- | --- |
| `01-life-kitchen.txt` | 生活情景，12 秒竖屏双人 | 接触级（端锅／擦肩）、竖屏双人错开站位、收尾动作链给足时间 |
| `02-action-alley.txt` | 动作，12 秒 16:9 一对三 | 单元数与写作密度声明、幅度（倒地／同时在场／低机位）、落地仍在动 |
| `03-product-perfume.txt` | 产品，12 秒 16:9 纯产品 | 材料变化、光与雾的关系、尺寸参照、全片禁文字 |
| `04-dance-guofeng.txt` | 舞蹈，15 秒竖屏单人 | 无参考图分支、主句／变奏／对比／高光／收尾、未见音频时不假装同步 |
| `05-life-entryway.txt` | 生活情景，15 秒竖屏双人 | 窄口可见、距离变化、一行一拍、收尾 2.5 秒、中景只写看得见的细节 |
| `06-sea-first-sight.txt` | 生活情景，15 秒竖屏单人 | 失恋后的复合情绪，只演两次转折：低头裹围巾 → 抬头第一次看见海的惊讶 → 放下手机、围巾被风带走；固定胸口以上近景、海退成虚化背景与声音，脸占画面约四分之一；不在正文写"失恋"背景故事，只用手机与围巾承担可见证据 |

示例用的是本技能模板的字段（角色绑定／服装／视角与摄影／场景／声音／镜头／执行要求），不是外部样本的五块式；外部样本只用来校准节拍粒度与密度，不提供结构。

## 怎么用

- **当尺子**：写自己的稿子前扫一眼同类那条，看它的字段密度、时间线颗粒度、约束写法。
- **不要照抄**：题材、人物、道具都不通用，抄结构可以，抄内容会得到一条不属于你的片子。
- **别当标准答案**：这些示例都经过自检修正（见下），但多数没有成片验证；它们证明的是"按要求写出来长这样"，不是"这样写一定好看"。

## 四条各自被自检改掉的问题

记录在这里，因为它们比示例本身更有用：

1. **物理不合理**：端汤时让另一个人"扶锅底"——锅底朝下且烫，改扶手肘。
2. **密度声明虚高**：初稿写"54 个单元、4.5 单元/秒"，逐段数下来只有约 43 个，改成 3.6 并降级为"刚过两倍下限"；同时补了一次单膝触地，让"每 5 秒倒地"真正成立。
3. **光向自相矛盾**：一边写"固定侧逆光"，一边写"光柱缓慢扫过瓶身"；改成"雾在流动、光边缘轻微晃动，光源方向不变"。另外补了瓶身尺寸参照。
4. **收尾超载**：舞蹈收尾 1 秒要装"停住＋回头＋呼吸"，按收尾动作链 ≥2.5 秒重排时间线，并补了缺参考图时的分支说明。
5. **中段不自然**（生成后反馈：开头结尾可以，中间不够真实）：三条原因叠在一起——① 起幅在操作台前、切到走廊，两镜空间接不上；② 窄口没被镜头建立，让位失去理由，两人隔一米站着对话；③ 切点 3.75 秒正好吃掉"转身看到对方"。改法：改成一镜到底、起幅带到门框与水槽夹出的 60 厘米窄口、写出 1.5 米→0.4 米的距离变化、让位按五拍写（看见／收身／错位／稳住／松气）。
6. **关键证据看不见**（生成后才发现）：生活那条写了"汤面晃到锅沿、一滴将溢未溢"，成片机位在胸口高度、低于锅口，只看得到锅壁——汤在锅里，但那两秒观众看不到液面。已补「机位略高于锅口 15 厘米、45 度俯看」，并把这教训写进[摄影与画面设计](../references/cinematography.md#容器里的证据要看得见)。
7. **情绪没出来**（生成后反馈：没有爱情片情绪片段的感觉，也没有微表情）：中景里脸太小、12 拍压进 15 秒、中途写了"眼睛又暗了"这类不可执行指令。改成胸口以上近景（脸占画面约四分之一）、6 拍、只留两次转折，并把"难受回潮"那层删掉；正文不写"失恋"背景故事，只保留手机反扣、围巾被风带走这些可见动作。规则见[生活情景创作方法](../references/life-scenes.md#情绪泄露与表演次序)。

## 边界

- 单元数、接触点这类东西**脚本查不出来**，只能人工数。第 2 条就是例证：lint 只检查"有没有写数字"，不检查数字真假。
- 示例里的时间线是写作规划，不是成片实测；实际节奏仍以生成结果为准。
