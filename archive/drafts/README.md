## 06-breakup-seaside.txt

15 秒竖屏单人生活短片《这三天》，失恋后去海边，想起这几天，最后释怀。

- **状态**：未生成验证。
- **故事**：见 `06-breakup-seaside-story.md`。故事写了三天（翻聊天记录、装箱、推掉饭局），视频只取海边这一刻，不拍闪回。
- **改法**：胸口以上近景（脸占画面约四分之一）、6 拍、两次转折（麻木 → 把脸埋进围巾的记忆 → 松开手）；时间改到黄昏转蓝调，红围巾成为唯一高饱和色；**全片只有围巾一件道具，没有手机**，记忆与放下都靠围巾完成。
- **关键取舍**：故事的结尾"是运营商短信"整段删除；屏幕给不出信息，还承担生成文字的风险，改为"把脸埋进围巾、被风吹开一条缝、最后松开让风带走"。
- **相关的待验证假设**：单段情绪转折 ≤2 次、情绪靠身体不靠微表情、背景故事不写进提示词。三条都来自失败成片的推论，见 `references/life-scenes.md`。
- **验证通过后**：改名为 `06-breakup-seaside.txt` 移入 `examples/`，在 `examples/README.md` 表格补一行，并同步"各条被自检改掉的问题"。
