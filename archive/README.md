# 归档说明

本目录不属于技能包，不随 仓库根目录 分发。

| 目录／文件 | 内容 | 为什么不放进技能 |
| --- | --- | --- |
| `preferences.md` | 早期会话里积累的个人偏好原文 | 是某一个使用者的历史记录，通用技能应写成[默认约定](../references/defaults.md)并允许覆盖 |
| `case-index.md`、`cases/` | 个人作品案例与最终提示词 | 属于个人创作资产，且含具体作品名与生成参数 |
| `sources/dance-choreography-director.md` | 外部提供的舞蹈导演文稿 | 第三方文稿，技能只保留改写后的方法 |
| `drafts/` | 写完但未通过成片验证的提示词稿 | 没经用户验收，不能当示例；通过后移进 `examples/` |

技能运行不依赖本目录中的任何文件。安装技能时客户端只会读根目录 `SKILL.md` 和它引用的文件，本目录可以不拷。
