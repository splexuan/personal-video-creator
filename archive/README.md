# 归档说明

本目录不属于技能包，不随 `skills/video-prompt-director` 分发。

| 目录／文件 | 内容 | 为什么不放进技能 |
| --- | --- | --- |
| `preferences.md` | 早期会话里积累的个人偏好原文 | 是某一个使用者的历史记录，通用技能应写成[默认约定](../skills/video-prompt-director/references/defaults.md)并允许覆盖 |
| `case-index.md`、`cases/` | 个人作品案例与最终提示词 | 属于个人创作资产，且含具体作品名与生成参数 |
| `sources/dance-choreography-director.md` | 外部提供的舞蹈导演文稿 | 第三方文稿，技能只保留改写后的方法 |

技能运行不依赖本目录中的任何文件。需要把技能单独分发时，只复制 `skills/video-prompt-director/`。
