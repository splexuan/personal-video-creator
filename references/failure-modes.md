# 已知失败模式

写正文前扫一眼，确认没有踩已知的坑；自检时也可以拿它当反向清单。每条只写「成片里看到什么 → 稿子里是哪句造成的 → 怎么改」，不写具体作品。

**证据边界**：这些条目来自项目归档里的十余条成片与反馈，是经验归纳，不是统计结论。数量少，遇到反例以实际观察为准，别把它当铁律。

**证据强度不一**：多数条目有多条成片支撑；「情绪全写在眼睛里」这一条，以及[生活情景](life-scenes.md#情绪泄露与表演次序)里那四条情绪规则，目前只有一条失败成片支撑，按待验证假设使用。

## 一、机制类：写完很细，但没有记忆点

| 现象 | 稿子里的根因 | 改法 |
| --- | --- | --- |
| 画面、光线、运镜都写满了，看完却说不出这条片子在讲什么 | 七个摄影决定全部填满，但从头到尾没有承诺任何一种观看方式；流程是通用的「走到某处—看到某物—有点感受」 | 回到[创意发散](creative-divergence.md)先选机制：这条片子是遮挡剥离、视差揭示、还是视线牵引？机制定了再写细节 |
| 同一条片子里换了三个创意，每个都只做一半 | 把「丰富」当成「多塞几个点子」 | 一条片子只让一个机制当主角，强度来自一次完整的兑现，不是三次半途而废 |

## 二、密度与幅度：动作片的两个独立失败

| 现象 | 稿子里的根因 | 改法 |
| --- | --- | --- |
| 打斗像减速、人物站在原地等时间；实测最长近静止 5 秒以上，且正好落在决胜段 | ① 持物只写状态（"抱住／举起／握住"）不给位移轨迹；② 每段结尾把动量写成"近零／收势"；③ 用"极短停顿／凝住"表达节奏的顿，生成端画成静态并保持数秒 | 每个持物动作给起点—路径—终点—时长；每段承接动量非零；节奏的「顿」一律改写成换一种运动（[动作密度](pacing.md)第四节） |
| 全片一直在动、没有死区，但看着不像打斗 | 幅度太小：人在原地高频摆手脚，没有倒地、没有大位移、没有第二个人同时动 | 每 5 秒至少一次「对手从站到倒」；画面里始终两人以上在动；改成抓握式持续接触；机位压到腰以下 |
| 动作密度靠切镜硬撑，越切越碎 | 以为打斗感来自快剪 | 切镜只会让运动最高点落在剪切那一帧；幅度与同时性才决定观感。切点落在动作进行到六到八成的那一帧 |

## 三、连续性：单看每段都对，连起来穿帮

| 现象 | 稿子里的根因 | 改法 |
| --- | --- | --- |
| 道具状态自相矛盾（锅盖开着又盖着、锅里空了又满） | 跨镜只写「当前动作」，没有交接上一镜结束时的状态 | 每镜结尾写六字段里本片需要的几项：位置、朝向、距离、动量、伤损、握持；下一镜从那句接起 |
| 情绪全写在眼睛里，成片一张脸到底，没有起伏 | 把微表情当指令写（眼睛暗下去、嘴角垮下来）；固定中景里脸太小，动作又被拆得太碎 | 单段只留 ≤2 次转折，情绪改由身体与道具承担；要"收"就给遮挡或转身；情绪戏用近景，别用中景硬撑 |
| 全片最大的画面变化来自环境（开门的光、灯闪、云影），人物动作被压平 | 光比或亮度突变盖过人物；环境变化和人物事件撞在同一拍 | 环境变化放到人物事件之后 0.5 秒，或让光只占画面一角；人物事件那一拍保持曝光稳定 |
| 地面／台面的道具数量没写死，画面里多出一双鞋、多一个杯子 | 只写"一双拖鞋"，没给总数；模型按常识补 | 起幅与结尾各写一次道具总数（如"地面只有一双拖鞋、一双球鞋"），换场后重申 |
| 后段场景里的东西凭空消失（道具、家具、墙面标识） | 换段或换场时只重建了人物，没重建环境锚点 | 换场时先写环境锚点（固定的门、窗、招牌、地面），再写人物 |
| 收尾承诺的动作没出现（写了"扣头"却停在半空） | 收尾句写的是结果名词，不是可见动作 | 收尾写成完整动作链：起手—接触—结果—余动；并在自检时确认时长够演完 |
| 参考图与文字冲突，成片两边各取一半 | 没有显式写明"不继承什么" | 每个素材写两件事：借用什么、不继承什么（如"面部按 @图片1，服装不继承参考图"） |
| 长稿后半段丢了前面的设定（改设定后更明显） | 关键设定只在开头写一次，中后段没有重申 | 固定块写一次 + 在时间线中段用一句短句重申；改设定时同步替换全稿旧描述 |

## 四、文字与声音：生成端会各自出错

| 现象 | 稿子里的根因 | 改法 |
| --- | --- | --- |
| 收尾字幕比稿子多一个字，同句配音也念错 | 烧入文字与同句配音都由生成端产生，字数越多越容易错；写了多句字幕就以为都会准 | 只保留一句必须逐字准确的；能改成画面可读就不靠字幕；成片到手后逐字核对画面文字，并单独试听该句 |
| 画面里出现没要的字幕，或字段标题被当成字幕渲染 | 用 `【】` 做字段标题，而官方语法里 `【】` 表示画面字幕 | 标题改 `▍字段`（见[默认约定](defaults.md)）；沿用旧稿时知道这一风险 |
| 人声语感不对（像配音腔、像外国人） | 用"大笑／起哄／喊"这类动作描述去指定语感 | 语感由场景与参考素材决定。需要特定语感时，把人声层单独处理（换素材或后期替换），不靠动作词 |
| 一条稿里两套质感逻辑互相抵消（"无磨皮"又写"磨皮感"；手机质感又写广告顶光） | 前后两段分别按不同风格写，冲突没改掉 | 一稿只留一套质感逻辑，发现冲突改正文，不是加一条"注意不要冲突"的检查语 |

## 五、机位与平台：模型会自己做主

| 现象 | 稿子里的根因 | 改法 |
| --- | --- | --- |
| 低机位被升高、侧面被切成正面 | 机位只写在开头总述，具体镜头没约束 | 机位是观看方式的一部分时，写进对应镜头句内："机位保持低""不切正面""自左向右平行跟拍" |
| 两人站着对话，擦肩而过没有发生 | 窄口不可见、没写两人距离变化，让位只剩结果 | 起幅交代窄口两端、写起始与最近距离、按五拍写让位（见[生活情景](life-scenes.md#让位与擦肩窄要看得见次序要写出来)） |
| 写了"汤面晃／箱里有东西"，成片只看到容器外壁 | 机位与容器口齐平或更低，平视看不到内部 | 写明机位高于口部 15–20 厘米、45 度俯看，或让人物把容器朝镜头倾斜 |
| 一句里写了两个主运镜（一边环绕一边推进），画面崩 | 复合运镜塞进一拍 | 一拍一个主运镜；确需两种就拆成相邻两拍（[机位可行性](camera-feasibility.md)） |
| 素材标签对不上、多人被认成同一人 | 用了"图1到图4分别是…"、或没写死数量 | 一个素材一行写归属；多视角素材显式声明同一主体并写死成片数量 |

## 怎么用

- **写正文前**：扫一遍第一、二节，确认机制和密度这两件事没有从根上错。
- **自检时**：按第三节逐镜对状态，按第四节核对文字与声音的写法。
- **拿到成片后**：发现新问题，先判断它属于哪一类；同类问题出现两次以上，再补一行到本表，并注明证据来自哪类片子。
