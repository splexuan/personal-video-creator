# 默认约定

没有特别说明时按本页执行。**本次任务的具体要求优先于这里的任何一条**，用户明确说过的做法不重复追问。

## 交付形态

| 项 | 默认 |
| --- | --- |
| 语言 | 提示词正文用中文交付；台词语言按剧情需要，并在句中声明 |
| 交付物 | 一条可整段复制的完整提示词。分镜报告、逐镜版、素材包只在用户要求时附上 |
| 结构 | 按类型与任务择优，不固定模块数量或字段名称。模板可增删、合并、改名、重排 |
| 篇幅 | 由设计需要决定，不设字数目标。关键画面写到可逐帧执行，其余交代清楚即可，不平均分配 |
| 说明 | 创作判断留在内部，不把来源分析、备选项、自检过程塞进正文 |

## 常用参数

| 项 | 默认 | 何时改 |
| --- | --- | --- |
| 生成平台 | 按用户所用入口；常见为 Seedance / 即梦 / Dreamina，也有可灵、Veo 等 | 语法与上限以[平台口径](platform-notes.md)为准，冲突时以实际入口为准 |
| 画幅 | 人物互动、生活、时装、UGC 常用 9:16 竖屏；叙事、广告、界面、车辆常用 16:9 | 按内容与投放位置选，不固定 |
| 时长 | 落在入口的单次能力区间内（已核对的 Seedance 系列为 4–30 秒，其他入口按实际界面） | 需要更长时先考虑分段或长视频模式，不假定某入口的上限等于平台能力 |
| 写实程度 | 按类型：生活、时装、广告偏写实；动画、DV、界面按各自画风 | 画风与方法从[可组合写法](../assets/modifiers/)里选，可叠加 |

## 字段标题写法

模板与稿件用 `▍字段名` 做小标题（例如 `▍人物锁定`、`▍动作分镜`），**不用 `【】`**：官方语法里 `【 】` 表示画面字幕，用它做标题有被渲染成字幕的风险（见[平台口径](platform-notes.md)第五节）。

需要延续旧稿，或实测确认所用入口不受影响时，可以改回 `【】`；同一份稿内保持一种写法，不混用。

## 参考素材

- 身份由上传的参考图绑定；多角度参考默认只锁面部与发型，服装、配饰以文字描述为准。用户另有说明时从其说明。
- 三视图属于同一身份，写稿时要显式声明并写死成片中的数量。
- 没有提供的素材用文字设定，不声称已绑定上传图，也不写引用标签。
- 缺舞蹈参考图时给取景建议与参考图提示词；用户明确要求或已授权时才生成图。

## 成本与验证

- **生成按次计费，成本随入口、分辨率、时长变化。** 因此默认先交付一条直出版，出片核对后再决定是否分段重做，不两版同跑。
- 文本推演能排除设计缺口，不能证明成片达标。身份漂移、手部变形、漏执行、字幕与配音偏差仍需看片核对。
- 证据分级沿用[平台口径](platform-notes.md)与[反馈与维护](feedback.md)：官方／多源一致／二手待核；自有经验指标标为"经验阈值"，不冒充平台规格。

## 可覆盖项

没有以下固定限制：主角性别、服装、发型、第一人称机位、反击式结尾、禁用音乐、全片无字幕、统一时长。这些按每条的题材与目标决定。
