# 摄影与画面设计

用于把一个想法发展成精美视频的完整新稿，或重做构图与镜头方案。与[导演设计](directing.md)、当前类型模板及[提示词自检](prompt-self-check.md)配合；纯对白、小范围修词不必重做摄影。以下是针对创作薄弱点补充的设计方法与文字示例，未声称经过本次视频生成验证，也不是新增外部来源的研读记录。

## 从抽象气氛落实到视觉选择

用户说“远离世俗”“温暖”“压迫”“自由”时，主动选择具体的观看体验：观众的注意落在哪里，空间怎样展开，人物或环境如何回应，结束时哪幅画面值得留下。设定应服务用户的题材，避免无关的都市闪回、强加冲突或旁白解释。

例如骑牛看草原，可以让一小段有重量的骑乘细节引入身体感，再让草坡边缘在前进中逐渐降低，露出更远的地形；风吹动近处草穗，最后停留在人与动物共享的片刻。这是本片可选的视觉路径，不是旅行片统一的三段式。

地点也需要设计。说明当前地形、路线、植被的高低疏密、光源与天气作用，而不是把“草原、树林、海边”当成完整场景。细节须在当前机位与时长中可见，不为丰富画面塞入大量动物、河流、花海或天气突变。

## 关键画面能具体画出来

为关键镜头或连续镜头阶段选择有作用的摄影信息，写入生成正文；不要求每镜填满所有字段。

| 摄影决定 | 需要说清的可见关系 |
| --- | --- |
| 视觉中心 | 第一眼看什么，占据画面哪里，其他物体怎样引导或让出注意力 |
| 空间层次 | 哪个近景提供尺度或遮挡，中景发生什么，背景怎样延伸；简单构图可以有意只保留少量层次 |
| 机位与透视 | 摄影机相对主体的高低、距离和朝向；近景放大、纵深展开或远景压缩应与摄影意图一致 |
| 光线 | 光从哪里来，照亮什么表面，哪里保留阴影，怎样显出轮廓、体积和材料；同场光线变化有原因 |
| 色彩与质地 | 具体物体之间的色彩、明暗和材料关系；写实保留适量不均匀纹理，不把所有表面磨成光滑模型 |
| 焦点与景深 | 当前必须清楚的对象、允许虚化的区域、焦点变化的触发与目标；开阔风景不默认浅景深 |
| 运动与落幅 | 从什么构图出发，跟随谁或显露什么，何时减速，最终停在哪里；也可以明确静止观察 |

焦段、帧率、快门或设备名称只在它们确实帮助表达时采用。标了某个镜头或摄影机品牌，不等于已经写出相应的透视、运动与质感。需要更长篇幅时，用它展开摄影和表演关系，避免追加一串互不相容的技术标签。

## 让整段画面有观看过程

镜头之间可依靠景别、视线、运动方向、遮挡显露、明暗或声音关系发展；选择当前主题需要的变化。一个近景接远景，应说明注意力如何从前一个对象转向后一个对象；不要仅按景别清单轮播。宏大航拍、绕拍和人物特写只在视点与目标允许时使用。

连续镜头也需要发展。摄影机前进时，近处物体与远山的位移关系，坡地遮挡的解除，人物或动物的身体响应，都能提供观看内容。不要要求山丘在短距离慢行中大幅漂移。转头应由可见或可听的对象引起，回望承接已经改变的位置。

安静的镜头可以长，但要知道停留在什么上面：动作尚在完成、光或风作用于具体物体、观察在加深、声音的距离和层次在改变。若只有相同景物和重复气氛词，重新安排内容或缩短停留；也不能以不断增加事件或快速剪辑破坏宁静。

从十五秒改为三十秒时，重新考虑主题需要的展开、停留和收束。可以延长确实值得观察的过程，也可以加入有联系的观察；不默认倍增动作数量、镜头数量或每段时长。

## 第一人称与身体支撑

先确认视角主人坐、站或行走在哪里，摄影机由谁持有或如何固定，再安排露手、腿、道具及镜头倾角。眼睛视点可以看局部身体；看见整个动物背部、两侧膝盖、双手、牛头和大片天空同时清楚，可能与坐姿、距离和取景冲突，应选择主要信息。

骑乘时可用一次轻微低头交代一侧膝盖、支撑和接触，再恢复前望。前望画面中动物只保留符合视线的局部；转向侧方后，牛头可以自然退出画面，不需要让它一直锁在中央。此处是取景选择，不能概括成所有第一人称镜头必须露手或必须隐藏动物。

身体起伏、手掌与皮毛接触、衣料运动、近景掠过、动物头耳或肩部响应，应由共同的运动引起。避免只描述摄影机轻晃而没有任何主体或空间响应，造成前景像固定贴图的感觉。没有连续看片时，不能只凭抽帧认定实际运动存在滑行或卡顿。

## 声音参与空间与情绪

明确近处接触、环境底声、远处声源的层次及变化。骑行中的衣料摩擦、草声或蹄声可以帮助建立身体感；视线转向某个声源后，声音关系仍有空间依据。需要音乐时选择与观看节奏一致的方向，并给关键现场声音留位置。

无音乐、无字幕、无对白是可选设计，不自动构成电影感。加入音乐也不能代替构图与表演。所有声音判断区分方案设计、用户反馈和实际听审。

## 文字展开示例

空泛写法：“骑牛缓慢前行，草原辽阔，镜头轻晃，氛围治愈。”

可执行的一个镜头：“骑乘者的视线朝前略向下，棕黄的牛耳和部分后颈落在画面下缘偏右；近处几簇高草先经过画面左侧，中景是一道缓缓下降的草坡，远处山脊暂时只露出窄窄一线。黄牛沿坡顶的平缓路线慢行，镜头跟随身体轻微起伏，近草向后掠过，远山几乎不动。随着前进，遮住远景的草坡边缘逐渐降低，背后的谷地展开。左后方低角度阳光照亮牛耳边缘和草穗，牛颈背光处保留棕色纹理。摄影机沿揭开的谷地微微抬起，在空间展开后停止抬头，留出看清远景的时间。”

这段示例增加了构图、空间、透视、光线、运动和落幅的实际决定。它不是完整影片，也不证明文字已生成成功。全片还须设计相邻镜头或阶段怎样承接、结尾怎样成立。

## 交付前的取舍

把稿件中的“精美、电影感、松弛、震撼”等词暂时遮住，检查具体镜头是否仍能支撑目标。若删去某项参数或形容词，预期画面没有任何变化，它可能没有贡献；若某个摄影细节决定了空间、表演可见性或情绪，应保留足够篇幅。

自检分别检查可执行性和观看体验。新稿可以写得充分细致，但画面质量、动物形体和运动仍需成片核对，不能把文本完整或字数增加当成效果保证。
