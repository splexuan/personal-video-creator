## 从案例选择写法

| 本次需要 | 重点案例 | 要取用的部分 |
| --- | --- | --- |
| 沉默中的矛盾情绪 | 泪眼持枪对峙、分手表演、出租车分手戏 | 保留外在任务，分阶段改变呼吸、视线、嘴角和动作意愿 |
| 冷面反转 | 踏水骗局、捡钱反转 | 观众先看见什么、真相何时揭晓、被揭穿者怎样回应 |
| 宠物捣乱 | 雨天小猫、镜前狗狗、虎帽猫 | 注意力目标、接近过程、触碰与人类的即时反应 |
| 轻松日常 | 洗衣、找回旧耳机、深夜做饭 | 正在进行的生活动作、小变化、恢复日常的收尾 |
| 微小幻想或反差 | 餐厅冻结、机器人与机械狗、水豚贴纸 | 清楚的异常规则、例外主体、现实细节和情绪终点 |
| 多素材与多段衔接 | 古董市集、机器人、双 prompt 拼接 | 各素材用途、同一空间的不同角度、上一段留下的状态 |

## 具体案例与迁移方法

### 1. 泪眼持枪对峙：外在动作维持，内在意愿反复变化

来源：[ZeroLu / x-sd25-01](https://github.com/ZeroLu/awesome-seedance-2.5/blob/a24d31c3909a30b97aec83e6b48867c4482cc68e/README-zh.md#泪眼持枪对峙)，[原作者 BubbleBrain](https://x.com/BubbleBrain/status/2084811218020340088)。

人物持续举着道具，决心却不断动摇；过肩构图把关系压力留在前景，焦点持续观察脸和手。紧张由呼吸、嘴唇与手指变化积累，结尾仍悬而未决。

迁移到生活戏时，可以写“递出的钥匙没有收回，想说的话却几次咽下”。固定外在任务后，只改变少量可见信号，让两种意愿同时存在。是否落泪、决断或保持悬念由新故事决定。

### 2. 分手表演与出租车分手戏：情绪变化有先后，也有残留

来源：[分手表演复拍分析稿](https://goodcase.ai/cases/seedance-3b9beb9a46d4)，[原帖](https://x.com/liyue_ai/status/2090378405288300626)；[出租车分手戏](https://goodcase.ai/cases/seedance-2-5-8d136b59e95a)，[原文来源](https://mp.weixin.qq.com/s?__biz=MzkwMzE4NjU5NA==&mid=2247519871&idx=1&sn=6c800d0dfcb8afb69c418751cdfd0d3b&gc=scene-taxi-breakup)。

前者细分声音落下、闭眼呼吸、抬眼对视、笑意消退、说出口和后撤。后者先在告别时强撑笑容，再在车内近景连续观察情绪失守；全片有切镜，连续的是关键表演段。

可用结构：触发 → 理解停顿 → 无意识反应 → 主动调整 → 回应 → 残留。写清“笑意只在嘴角”“说完仍看着对方”等可以看见的关系。小幅遗憾、明显崩溃都能成立，强度与音乐按本片选择，不把《明天》的克制推广为唯一表演方式。

### 3. 踏水骗局：构图控制真相，反应兑现笑点

来源：[完整提示词与复测记录](https://goodcase.ai/cases/water-walking-xianxia-fraud)，[原作者 Soranlan](https://x.com/Soranlan/status/2081379282442420321)。

先展示似乎不可能的动作，再降低机位看见水下承托物，最后观察高人姿态怎样失守。前后位置对应，真相是同一场景中原本存在的原因。配乐在揭晓时收住，安静的补充回应完成收尾。

迁移到生活戏时，先安排“观众以为怎样”，再说明“实际靠什么完成”。在【场景】定位真相道具，在前镜规定是否遮挡，揭晓后为人物反应留时间。不要让解释道具在最后凭空出现。

### 4. 捡钱反转：一件道具串起完整因果

来源：[捡到钱立刻花掉的街头反转喜剧](https://goodcase.ai/cases/seedance-14-77-9-16-576-1024-30fps-de6ac984ad6a)，[原作者](https://x.com/john87445528/status/2097656268856905862)。

纸币掉落、被发现、被捡起、递还遭拒、仍在手中、被用于新的目的。人物从热心转为突然有主意，变化发生在得到新信息之后。

取用“道具所在位置与角色判断一同推进”的写法。需要转手时说明谁接住；没有接住就保留原持有者。原稿的精确时间、造型展示、标题字幕和长定格不自动进入新片。

### 5. 雨天小猫与镜前狗狗：先注意目标，再逐步靠近

来源：[小猫抢发圈](https://goodcase.ai/cases/seedance-she-thought-it-was-going-to-be-a-peaceful-rainy-day-selfie-f0bf765977dd)，[原帖](https://x.com/Strength04_X/status/2098256490238755226)；[狗狗抢镜](https://goodcase.ai/cases/seedance-pov-you-wanted-a-cute-mirror-selfie-but-your-dog-wanted-to-be-the-main-charac-3d3e83219d46)，[原帖](https://x.com/Strength04_X/status/2097616213371478242)。

小猫被手边的小物吸引，先看、伸爪、抓住，再攀到肩上靠近镜头。狗从低处进入倒影、被注意、跳起遮住人脸，最终调查手机。人的笑、撤手或调构图都由实际动作引起。

动物戏先写它看见什么、目标在哪里、怎样准备和接触；人类的判断与回应另写。非拟人写实动物使用耳朵、头部朝向、身体重心和叫声表达，不添加人类口型。自拍时同时分配持机手与互动手。数量沿用本片，猫狗双角色无需套用原稿的单宠物限制。

### 6. 洗衣与找回旧耳机：小事件也能有完整起伏

来源：[ZeroLu / x-sd25-05](https://github.com/ZeroLu/awesome-seedance-2.5/blob/a24d31c3909a30b97aec83e6b48867c4482cc68e/README-zh.md#韩式洗衣日常)，[原作者](https://x.com/doctorwasif/status/2083779989414019109)；[找回旧耳机](https://goodcase.ai/cases/seedance-the-goal-isn-t-to-make-ai-look-perfect-1afdf422cbe7)，[原帖](https://x.com/Just_sharon7/status/2098681428280279512)。

洗衣中的污渍、错配袜子和沉重床单形成自然反应；整理厨房时发现旧物，经历疑惑、辨认和笑意，再继续清理。两者都把人物放进正在做的事里。

可用“进行中的任务 → 小阻碍或发现 → 判断变化 → 回到任务”构思。收尾可以继续做事、看一眼成果或拿起下一件物品；不要求每条生活短片都反击、切黑或再加反转。

### 7. 纪实漫步与后台 vlog：摄影和声音参与反应

来源：[ZeroLu / x-sd25-08](https://github.com/ZeroLu/awesome-seedance-2.5/blob/a24d31c3909a30b97aec83e6b48867c4482cc68e/README-zh.md#70-年代地中海纪实漫步)，[原作者](https://x.com/hey_am_cherry/status/2083561941004685471)；[x-sd25-12](https://github.com/ZeroLu/awesome-seedance-2.5/blob/a24d31c3909a30b97aec83e6b48867c4482cc68e/README-zh.md#韩流后台-minidv-vlog)，[原作者](https://x.com/frametheory058/status/2083504893827100872)。

猫经过使拍摄者稍避让，人物离开后摄影稍迟跟上；后台的人物听见欢呼，视线、轻笑与呼吸发生变化，随后回应画外的工作提醒。

需要手机随拍感时，写明具体事件导致的倾斜、失焦或重新构图，不持续叠加随机晃动。声音同时写距离和遮挡，例如门后的闷响变近；先让角色有可见反应，再推进动作。仍保证关键表情可读。

### 8. 时间冻结系列：异常规则限定到主体与状态

来源：ZeroLu 的[过山车假发](https://github.com/ZeroLu/awesome-seedance-2.5/blob/a24d31c3909a30b97aec83e6b48867c4482cc68e/README-zh.md#过山车假发翻车现场)、[餐厅定格回放](https://github.com/ZeroLu/awesome-seedance-2.5/blob/a24d31c3909a30b97aec83e6b48867c4482cc68e/README-zh.md#50-年代餐厅定格回放)、[早餐逃逸](https://github.com/ZeroLu/awesome-seedance-2.5/blob/a24d31c3909a30b97aec83e6b48867c4482cc68e/README-zh.md#餐厅时间冻结早餐逃逸)。分别为 x-sd25-06、13、18。

事故发生后，一位角色能够移动，其他人和物保留指定状态；修补、倒回或恢复时间对应不同结局。人物面对奇观却处理一件小事，反应差距形成笑点。

日常幻想可写“异常发生于谁、谁例外、何时结束、结束后物品在哪里”。冻结、倒放、定格是不同状态，分别描述。更换结局时改变人物的选择，不能只换场地再重复同一修复过程。

### 9. 机器人与机械狗：愿望与结果可以有距离

来源：[完整提示词](https://goodcase.ai/cases/aimikoda-seedance-ai-3e98e88a068f)，[原作者 aimikoda](https://x.com/aimikoda/status/2089697506296737930)。

看到电视里的飞行，引出一起采花、制作颜料和重新涂装。角色没有飞起来，情绪却在共同尝试和最后的对视中完成。参考图分别控制同一对角色、建筑内部和同一建筑的两个外部角度。

取用“愿望 → 尝试 → 可见变化 → 对结果的回应”。温暖结尾可以来自陪伴或微小成果，不必补出能力升级。造型变化写材料来源和发生的时间；多个建筑视图应合成同一空间。

### 10. 古董多参考与双 prompt 拼接：保留生成方式

来源：[ZeroLu / x-sd25-20](https://github.com/ZeroLu/awesome-seedance-2.5/blob/a24d31c3909a30b97aec83e6b48867c4482cc68e/README-zh.md#古董市集多参考镜头)，[原作者](https://x.com/CuriousRefuge/status/2085050286910120376)；[双 prompt 案例](https://goodcase.ai/cases/youralphamom-seedance-ai-9afbf3248f50)，[原作者](https://x.com/YourAlphaMom/status/2089412506716721609)。

古董案例把身份、布局、地点、材质与调色分开指定；双 prompt 案例明确为两段各十五秒生成后手工拼接，第二段使用前段人物截图。

分别学习素材分工和衔接状态。长片若需分段，固定上一段末态与下一段起态的身份、服装、道具、方向和光线。案例总成片时长不自动表示单次生成时长；这项写法按实际入口需要使用，不把十秒生活戏改成多段工程。

## 写进现有七模块

| 模块 | 案例补充的决策 |
| --- | --- |
| 【角色绑定】 | 素材职责、实际角色数量、当下不同意愿；混合画风时分别绑定主体与环境 |
| 【服装】 | 道具持有者、转手过程、变化前后的结构和不可逆状态 |
| 【视角与摄影】 | 摄影机由谁持有；观众当前看见什么；揭晓与关键反应是否清楚 |
| 【场景】 | 原因或真相道具预先存在的位置；移动路线和接触目标 |
| 【声音】 | 触发声的距离、遮挡与时间；对白后回应；音乐进入或收住的具体时机 |
| 【镜头】 | 判断变化、短暂反应、主要动作、后果；结尾保留的动作与情绪 |
| 【执行要求】 | 只重复本片的关键约束，如异常作用范围、同一道具去向、指定终点 |

## 其余已读案例的用途

LearnPrompt 本次读了八条 dialogue-performance-beats 分类文本；另选读十条生活或反转喜剧、四条宠物互动、四条日常或情感过程。除上面详述者，还包括水豚厨房贴纸、女巫变鸭、土耳其冰淇淋、断 WiFi 的家庭喜剧、女儿背包家庭场景、灰猫误触厨房按钮、虎帽猫野餐、深夜做饭等。

可以分别借鉴单镜主要动作、错误结果后的反应、重复失败后改变策略、隐藏帮助者揭晓、动物目标和风格分工。贴纸角色的夸张形变属于其画风，不套给写实猫狗；原稿里的拟人动作也需按新片是否拟人选择。短的对白片段可学习回应顺序，不作为整条脚本的时长依据。

实际应用时选择最相关的一两种写法，放入本片七模块。保留外部案例来源和已有验证状态；新片的最终提示词与反馈仍按[反馈流程](feedback.md)积累。
