# 提示词研读提炼的方法

本页只保留能迁移到当前创作的表演、摄影、动作与状态组织方法，不保存外部样片介绍、视频地址或网址。按本片选择相关写法，字段名称、数量与顺序均可调整。

## 方法来源与范围

方法整理自 ZeroLu 的 awesome-seedance-2.5 提示词资料、LearnPrompt 的 awesome-seedance 提示词资料及本会话的参考分析。已研读前者 21 条完整记录，累计选读后者 47 条，其中包括两条分镜页生图稿。提示词研读、成片观察与个人重新生成是不同证据，方法摘要不代表新片已经验证成功。

## 按当前需要取用

| 当前需要 | 可迁移的写法 |
| --- | --- |
| 沉默中的矛盾情绪 | 保留外在任务，让视线、呼吸和动作意愿分阶段改变 |
| 情绪转变与余情 | 触发、理解、主动调整、回应和残留有先后，反应留出容量 |
| 冷面反转 | 控制观众看到原因的时间，揭晓后让人物反应兑现笑点 |
| 道具因果 | 位置、持有者、开合和用途随事件变化，后镜继承实际结果 |
| 动物捣乱 | 注意目标、准备、接近、触碰和即时反应连续可读 |
| 轻松日常 | 进行中的任务、小阻碍或发现、判断变化、自然收尾 |
| 荒诞事件与随拍 | 限制条件可见，触碰改变状态，摄影关注路径跟随后果 |
| 微小幻想 | 异常作用对象、例外主体、时机与恢复后的状态清楚 |
| 多素材与分段 | 素材职责明确，各段保留自己的身份、起态、末态与衔接 |

## 矛盾情绪与连续反应

固定一个持续的外在任务，再让角色想做又收回的意愿通过少量可见信号改变。例如递出的钥匙没有收回，话到嘴边却停住。重要表演段可以持续观察，不按每句台词机械换镜。

情绪变化可考虑“触发 → 理解停顿 → 无意识反应 → 主动调整 → 回应 → 残留”。说明笑意在哪里、视线何时结束、手边动作是否恢复；是否落泪、决断或保持悬念按本片选择，不把克制变成唯一表演方式。

## 构图揭晓与道具状态

先安排观众以为怎样，再定位真实原因、何时看见及人物如何回应。真相道具在需要时已经存在，取景与遮挡实际控制可见范围，不在结尾凭空补出解释。

道具转手时说明谁接住；没有接住就保留原持有者。掉落、发现、拾起、交还或改作新用途分别留下对应状态。角色的判断和选择由得到的新信息引起，反应与后果有时间被看清。

## 动物行为与日常收尾

动物戏先写它注意什么、目标在哪里、怎样准备和接触，人类判断与回应另写。写实动物可用耳朵、头部朝向、身体重心和叫声表达行为，拟人程度由本片确定。自拍同时分配持机手与互动手，数量沿用当前故事，不沿用外部素材的单角色限制。

生活情景可用“进行中的任务 → 小阻碍或发现 → 判断变化 → 回到任务”构思。收尾可以继续做事、看一眼成果或拿起下一件物品；不要求每条都反击、切黑或追加反转。

## 拍摄者注意力与异常规则

随拍的倾斜、避让、失焦和重新取景由具体事件触发，保留关键表情、接触和后果的可读性。摄影可先看整体，再注意触发者，发生变化后追踪结果；不持续叠加随机晃动。

把异常的限制条件落实成支撑、连接、开关或遮挡等可见状态。写清小动作碰哪里、限制怎样解除，以及规模、速度、距离或环境响应怎样体现巨大后果。声音也可引出注意力变化，但距离、遮挡、归属和回应时机要清楚。

冻结、倒放和定格分别描述作用主体、例外、开始与结束，恢复后物品状态对应。更换故事时改变角色策略、选择与结果，避免只换地点重复同一修复过程。

## 愿望、尝试与可见变化

可用“愿望 → 尝试 → 可见变化 → 对结果的回应”组织温暖或奇幻片段。情绪终点可以来自陪伴或微小成果，不必补出能力升级。服装、材料或场景改变说明发生的时间与原因，多个参考角度明确属于同一空间。

## 素材分工与分段衔接

把身份、造型、布局、材质、调色、声音与实际首帧分别指定到素材。图板排版不变成额外角色，角色身份参考不自动固定视频构图。

确需分段时保留前段末态与后段起态的身份、服装、道具、朝向和光线，按实际入口选择衔接方式。总成片时长不代表单次生成上限，也不把简单短片扩成不必要的分段工程。

## 落到当前提示词

按当前目标选最相关的写法，放进素材、主体、表演、摄影、声音或时间线。生活情景的七模块只是一种参考组织方式，产品、舞蹈、界面和过程片使用自己的字段；空项删除，关键信息不遗漏。

拍点、时长、分辨率、上传标识、摄影设备与声音限制按本次材料和实际入口确定。贴纸或卡通的形变不套给写实角色，短的表演片段不当成完整脚本的时长依据。新片结果按[反馈方法](feedback.md)积累；此页仅保存方法。
