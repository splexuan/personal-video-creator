# 动作密度与节奏

用于写多段动作片、打斗、追逐、群战、冲撞，以及任何"应该一直在动"的短片。这一册解决的是**成片看起来像减速、站在原地等时间，或者一直在动但不像在打**这一类问题——它几乎从不出现在画面描述里，而是由稿子的**动作密度与动作幅度**决定的。

配套读取：[动作与受力语法](action-craft.md)（每一击怎么受力）、[机位可行性与冲击预算](camera-feasibility.md)（机位怎么走）、[共用写法](video-core.md)（人物与质感）。本册管三件事：**一秒里发生几件事（密度）、每件事把人移动了多远（幅度）、它们怎么接上下一件（节拍）**。密度不够会慢，幅度不够会"忙而不像打"，两者是两道独立的关。

---

## 一、这条经验从哪来（一次可复现的失败）

一次 30 秒成龙风格打斗的实测，画面质感被用户认可，但用户判定"打斗不流畅、节奏不紧凑、好像减速了一样、站在原地等时间"。对成片做了逐帧量化，结论是**问题全部出在稿子**：

| 证据 | 实测数据 |
| --- | --- |
| 逐帧运动能量（相邻帧差分灰度均值，0–255） | 全片均值 4.51。但 **19.42–24.67 秒连续 5.29 秒低于 1.5**，是全片最长死区 |
| 死区落点 | 正好是原稿写明的**全片决胜点**（决胜一击那一整段） |
| 全片运动最高点 | 25.0 秒（均值 11.08）＝一次床单掠过，**不是**决胜点 |
| 帧复制检查 | 721 帧全部保留、**零重复帧** → 不是编码问题，是内容本身慢 |
| 场景切换点 | 10.0 / 14.96 / 19.38 / 24.75 秒 → 分段结构被遵守，**问题不在分段，在段内密度** |
| 21 秒那一帧 | 主角双手横持道具、对手直立站着，**这个姿态保持了 5 秒** |

原稿对应的原文是"伸手摸到那条鱼，双手抱住鱼身当棍，抡圆甩出去"。生成端只实现了"**双手抱住鱼身**"这个状态，然后停在这个状态上。

**四条可直接复用的结论**

1. **稿子的密度上限就是成片的密度上限。** 原稿是 30 秒 6 个动作事件（0.2 单元/秒），成片就是慢的。写多不一定全演出来，写少一定演不满。
2. **持物状态会被渲染成静态姿态。** "握住／抱住／举起／端起／扶着／端着"这类描述，生成端倾向于把画面停在那个姿势上。**必须同时给出位移轨迹。**
3. **"极短停顿"是无效且有害的指令。** 原稿写了"画面极短地凝住约 0.2 秒"，生成端不理解 0.2 秒，它按"静态"画，结果是 5.3 秒的静止。**凡是节奏上的"顿"，一律改写成"换一种运动"。**
4. **为了拼接安全而让每段动量归零，代价就是全片变成摆拍。** 原稿的分段模板要求每段写明"动量"字段，而每一段都填了"动量近零／收势"——这等于逐段向生成端下达"结尾停下来"的指令。

## 二、密度指标：先定数量，再写画面

**动作用"单元"计量。** 一个动作单元＝一次可被看见的位置改变、一次接触、或一次明确的受力反应。举例：

- "他侧身" ——1 个单元
- "对手一拳打空砸在卷闸上，卷闸凹进去一块" ——3 个单元（出拳、落空、卷闸变形）
- "他因为这半步滑了一下，顺势把手里那锅汤往前送" ——2 个单元（打滑、送锅）

### 两个计数必须分开：主要动作 vs 动作单元

这是最容易犯、也最难自查的一个错——**把"一个主要动作"当成"一个单元"来数，于是误以为密度够了。**

| 计数 | 定义 | 一个 30 秒动作片里该有多少 |
| --- | --- | --- |
| **主要动作（beat）** | 观众能概括成一句话的事件（"他把整锅汤泼出去"） | 每 2–4 秒 1 个；**决胜段（最后约 3 秒）不超过 3 个**（[单段直出能力框](camera-feasibility.md#四单段直出能力框)的规定） |
| **动作单元（unit）** | 主要动作内部的可见位置改变、接触与受力反应（"锅从腰侧被端到胸前，汤面在锅沿上打了一个来回"＝1 个） | 1.8–2.5 单元/秒 |

**关系**：一个主要动作里应该展开**四到六个单元**。写成"一个主要动作＝一个单元"，就是上一版慢的根源。

两个上限不冲突，因为它们量的是不同的东西：能力框限制的是**事件层**的密度（观众要记住的事不能太挤），本册限制的是**肌理层**的密度（每件事内部不能只有一下）。**动作片要的是"事少、动作多"**——观众能一句话说出这段在干什么，但那句话对应的是满屏不停的位置改变。

**目标密度**

| 类型 | 单元/秒（落地值） | 说明 |
| --- | --- | --- |
| 纯打斗、格斗片 | 1.8–2.5 | 低于 1.5 就会显得慢 |
| 追逐、跑酷 | 1.5–2.0 | 位移本身占大部分单元 |
| 有对白穿插的对抗 | 1.2–1.8 | 对白句之间不能出现"双方都不动" |
| 群战、混战 | 2.0–3.0 | 前后景各自有事件，可以叠加 |

**写作量必须是目标的两到三倍。** 生成端会大幅打折——实测中约只落地三成。所以：

```
写作目标 = 目标落地密度 × 2~3
```

30 秒打斗、目标落地 1.8 单元/秒 → **写作量约 25 秒段 × 3 ≈ 75–100 个单元**。低于 60 基本可以断定成片会慢。

**自检口径**：写完后数一遍单元总数，除以时长，得到"写作密度"；同时数一遍主要动作数。写作密度低于目标落地值的 2 倍，回去补动作，不要靠形容词加力。

**分段生成时，段长不得小于平台下限 4 秒**（见[平台口径](platform-notes.md#七时长分辨率与入口)）。这也意味着：**不要靠缩短段长来提高密度**——密度来自段内写了多少单元，不来自段有多短。5 秒一段写 3 个主要动作、15 个单元，和 3 秒一段写 1 个主要动作、1 个单元，是完全相反的两件事。

## 三、幅度：密度够了，为什么还是不像打斗

第二次实测。稿子已经按密度指标写足（30 秒 94 个单元，成片实测**无死区**、最长近静止 0.12 秒），用户仍然判定"节奏一点都不好、根本没有打斗的感觉"，并给出一条参照片说"这个才叫打斗"。

把两条成片放到同一把尺子上，差别不在频率，在**幅度**：

| 指标 | 参照片（用户认定的打斗感） | 我方成片 | 差距 |
| --- | --- | --- | --- |
| 运动能量均值 | 5.50 | 4.91 | 只差 11% |
| **高强度帧占比（>8.0）** | **24.3%** | **7.6%** | **3.2 倍** |
| **爆发帧占比（>2×自身中位）** | **9.3%** | **4.0%** | **2.3 倍** |
| 逐秒峰均比（一秒内最猛一帧 ÷ 该秒均值） | 2.96 | 2.02 | 1.5 倍 |
| 单帧最大运动能量 | 54.1 | 33.4 | 1.6 倍 |
| 音频峰值距满刻度 | 1.6 dB | 6.7 dB | 5.1 dB（打击声没打实） |
| 强打击点（峰值 > −3 dB） | 2 个 | **0 个** | — |

**结论一句话：均值只差 11%，强度分布差 3 倍。** 我方成片是"一直在小幅动"，参照片是"一顿一顿地大动"。密度管的是"一秒里有几件事"，幅度管的是"每件事把人移动了多远"。**两把尺都得过。**

**参照片是什么**（用户提供的参照短片，不是本机已验证的自有案例）：竖屏 720×1280、24fps、33.6 秒，街头一对多的多人格斗。它的构成为——主角空手，对手四到五人、轮次上；机位全片压在腰部以下，多处接近地面；几乎每两秒就有人被摔到地上，被打倒的人留在地上继续挣扎；33 秒里只有 4 个切点，主体大约 30 秒一气呵成。**它证明打斗感可以不靠快剪获得**，但必须靠幅度、同时性和低机位。

### 幅度怎么量

- **写稿口径：画面高度倍数。** 一个动作单元里，人物（或被摔的对手）在画面中移动的距离 ÷ 画面高度。目标：全片至少 **6 个单元位移 ≥ 0.5 个画面高度**，其中至少 **2 个 ≥ 0.8**。
- **成片口径**：`scripts/fight-metrics.py` 的五项读数（见第七节）。上表就是标尺。
- 幅度不足的稿子有一个共同长相：人物都在原地，靠手脚高频摆动制造"忙"。生成端会忠实照做——**手在动，人没动**。

### 什么写法才带幅度（四条）

1. **把人放倒，而不是打一顿。** 每 5 秒至少 1 次"对手从站立变成倒地"，全片至少 6 次。人被摔到地上，单帧变化量天然就是大的——这是最省力的幅度来源。**被打倒的人要留在地上继续挣扎、爬起，不要站起来归位。**
2. **多人同时在场，轮次攻击。** 画面里至少两名对手在同时运动：一个正在挨打，另一个已经扑到一半。参照片是一打四；我方稿子是一打二，而且第二个人大部分时间在等——**"等"是幅度杀手**。
3. **抓握，而不是对轰。** 肉搏的接触是持续的：抓衣领、抓手腕、抱腰、锁颈。抓住对方的人会把对方一起拖动，两个人的位移叠加；"打一拳就分开"只有一方的拳头在动。
4. **机位低于腰。** 镜头高度不超过人物腰部，全片至少三处接近地面。低机位让每一次倒地、每一脚跨步都压满画面；**齐胸机位会把大动作拍成小动作**。

**替换表**

| 会被画成"在动但不像打" | 改成带幅度的写法 |
| --- | --- |
| 他一拳打中对手的脸 | 一拳打中对手的脸，对手的头带着整个上身转了半圈、脚底离地、横着摔进墙角的积水里 |
| 他踢了对手一脚 | 抬腿踹在对手小腹上，对手整个人向后滑出两米、后背撞在铁闸上、顺着铁闸滑坐下去 |
| 两人扭打 | 他抓住对手的衣领往自己这边拽、同时侧身让开，对手冲过来收不住、从他身边擦过去撞在台阶棱上 |
| 他被打得后退 | 他被一拳打得双脚离地、整个人撞在木板上、木板裂开、他顺着墙滑坐到地上 |

### 一个被推翻的推论

"打斗感来自快剪"——**不成立**。参照片是 33 秒里只有 4 个切点的长镜头段落（主体 30 秒一气呵成）。切镜频率不是打斗感的来源，幅度、同时性和机位高度才是。

反过来也成立：**靠切镜救不了节奏。** 切镜只会让全片运动能量的"最高点"落在剪切那一帧上——那是剪辑的运动，不是人的运动。我方上一条成片的运动峰值恰好就落在转场，与这一条相互印证。

## 四、四条硬写法

### 1. 持物必带轨迹（最关键的一条）

**不写**："他双手抱住那根鱼，抡圆甩出去。"
**要写**："他松开头顶的锅、让锅从头顶左侧划一道弧到右手上方、在腰的高度换成右手托住。"

规则：**每一个"端起／举起／握住／放下／接住"的动作，都必须同时写出"从哪个点移动到哪个点、经过哪条路径、用多久"。** 只写状态不写位移，画面就会停。

同类替换表：

| 会被画成静止的写法 | 改成位移写法 |
| --- | --- |
| 双手抱住鱼身当棍 | 鱼尾从画面左下起、横划到右上，落点是对手手腕外侧 |
| 他举起凳子挡在头顶 | 凳子从腰侧翻过头顶、凳面朝上迎住下落的棍 |
| 他抓起短棍 | 右手从地面抄起短棍、棍头由下往上甩到与肩同高 |
| 他端起那锅汤 | 锅从腰侧被端到胸前、汤面在锅沿上打了一个来回 |

### 2. 情绪和痛感一律写在动作里

**禁止**："他愣住""他站定""他抬头看""他保持着姿势""双方对峙""他停下来喘气"。

**改成动中反应**：

- "愣住" →"他的视线跟着锅往上偏了一下，脚已经在往侧后方撤"
- "抬头看" →"他一边侧身让过一边抬眼看对手那只手"
- "疼得缩手" →"他缩着手的同时已经把身体转向侧面、另一只脚往后退了半步"
- "停下来喘" →"他退到墙边的一步里吸了一口气、肩还在起伏，人已经贴上墙"

**一条自查**：写完在全稿里搜"停、愣、站定、保持、凝住、对峙、不动"。搜到就改。

### 3. 每段承接动量必须非零

分段生成时，每段开头必须写明"上一段末尾**谁正在往哪个方向动、多快**"。这一句是防止成片断成一组摆拍照片的唯一手段。

- 好：接上段末帧——对手的脊背刚撞上铁闸、正在往下滑；主角身体侧向铁闸、手正在往锅的方向伸。
- 坏：接上段——主角站在画面中央，对手在他面前两米处。（这是**静止**，下一段必然是"摆好姿势再开打"）

**任何一段都不允许以"动量近零／收势／站稳"结尾。**

### 4. 切点落在动作进行到六到八成时（cut on action）

段与段的切点，要落在动作**还在进行**的那一帧，不是动作做完之后。落到动作完成之后，等于每一段都等一次"停"，全片被切成一组完整的起手—收手，观感就是"站在原地等时间"的剪辑版。

写法：在每段末尾写"切在……刚碰到／刚开始转向／身体还在往前冲的那一帧（约七成）"，并明确"不拍他站稳／不拍他停下"。

**注意**：不要为了拼接方便而给每段都安排一个"遮挡尾帧"。遮挡本身是一种停顿仪式；每段都遮挡，节奏会被切碎。遮挡只在真正需要跳时间或跳空间时用，全片两处足够。

## 五、节奏型：不许匀速

全片动作密度必须是一条**起伏的曲线**，不能是平直线。港式动作片最常用的一种：

```
密  →  密  →  顿  →  更密  →  收
```

- 前段就**已经在打**，不写起手式、不写对峙、不写"两人对视"。
- 中段加速度：单元/秒逐步提高。
- **中后段安排一次低谷**——但低谷必须是"换一种运动"，不是静止。可用的低谷写法：物体脱手飞起、人物翻身跌落、镜头跟随一个抛出的东西、一件东西从画面这头滚到那头。**静的不是画面，是"打击"这件事。**
- 低谷之后是最密的一段，把前面攒的势一次放掉。
- 收尾仍在动：镜头还在移、人还在走，不摆胜利造型、不站定。

**算例**（30 秒打斗，写作量口径）

| 段 | 时间 | 单元数 | 单元/秒 | 局势 |
| --- | --- | --- | --- | --- |
| 1 | 0.0–3.0 | 7 | 2.3 | 开场就在打，对手第一拳已经落空砸在硬物上 |
| 2 | 3.0–6.0 | 10 | 3.3 | 被扫腿、跳、落地踩滑、扑倒、肋上挨拳 |
| 3 | 6.0–9.0 | 10 | 3.3 | 趴地换手、膝顶、肩撞硬物、砸到第二个人 |
| 4 | 9.0–12.0 | 10 | 3.3 | 上台阶被拽回、反击、跳上、脚踝被抓 |
| 5 | 12.0–15.0 | 12 | 4.0 | 滑下、硬物相撞、踩手、两人争一件东西 |
| 6 | 15.0–18.0 | 9 | 3.0 | 单手连击三下、每下带晃、被踹肘、**东西脱手** |
| 7 | 18.0–21.0 | 8 | 2.7 | **低谷但仍是运动**：东西在空中，双手空出来连打三下 |
| 8 | 21.0–24.0 | 11 | 3.7 | **全片最密**：单手接住、踹开、推脸、转圈甩人 |
| 9 | 24.0–27.0 | 10 | 3.3 | 退上台阶、泼出、扣住 |
| 10 | 27.0–30.0 | 8 | 2.7 | 收势仍在动：端着空物、走进门、镜头一直后拉 |

合计 95 单元 / 30 秒 ＝ 3.2 单元/秒（写作量），落地约 1.8–2.2。

## 六、机制层面：让"不能停"变成故事条件

密度不能只靠写作技巧堆，**最好的办法是让故事本身不允许主角停下来**。可用的结构：

| 机制 | 为什么它自带密度 |
| --- | --- |
| **手里有件不能放下的东西**（滚汤、活物、满杯、易碎品） | 手被占用 → 每一击都只能单手完成 → 每次发力都要重新平衡 → 动作单元自然翻倍；且这件东西的状态（满→半→空）成为观众看得见的代价计数器 |
| **有个必须按时到达的目的地** | 主角有欲望，动作有方向，不会变成原地互殴 |
| **对手也要同一件东西** | 争夺中心物 → 双向欲望 → 不是单方面挨打，任何一方都不会停 |
| **空间只容一人／必须借力环境** | 每换一个位置就要处理一个新障碍，动作密度由空间强制供给 |
| **一直在动的东西**（蒸汽、风里的布、滴水、晃的灯） | 保证画面里没有一帧是纯静止的；这是给生成端上的一道保险 |

**避免的机制**：道具接力（一件一件用完）——它天然产生"用完一件→停一下→再拿下一件"的节奏，是密度的敌人。要收集式地使用道具，就让每次取用都发生在移动和受击中，而不是"他走过去拿起"。

## 七、成片实测：怎么客观证明"慢不慢、打不打"

拿不到主观评价时，可以直接量。**两套读数各管一件事**：`motion-audit.py` 管"有没有在动"，`fight-metrics.py` 管"动得够不够大、打没打实"。

**运动能量**：取相邻帧的差分图，求平均灰度值；数值越低越静止。做法见技能内 `scripts/motion-audit.py`。

**判据（密度）**

- 出现**任何连续 2 秒以上、运动能量持续低于全片均值的 1/3** 的区间 → 节奏失败。
- 全片运动能量的**最高点应当落在决胜段落**。如果最高点落在别处（比如一次转场、一次布料掠过），说明重音配错了。
- **帧复制检查**（如 ffmpeg `mpdecimate`）保留帧数＝总帧数，说明"慢"不是编码或补帧问题，是内容本身慢。

**幅度与打击声**：做法见技能内 `scripts/fight-metrics.py`，输出五项读数与音频峰值分布。对照第三节的标尺判断：

| 读数 | 及格线（按参照片标尺下调） |
| --- | --- |
| 高强度帧占比（运动能量 > 8） | ≥ 20% |
| 爆发帧占比（> 2× 自身中位） | ≥ 9% |
| 逐秒峰均比 | ≥ 2.9 |
| 单帧最大运动能量 | ≥ 50 |
| 音频峰值距满刻度 | 全片至少有 2 次 ≤ 3 dB（**听得出"打实了"**） |

**只有密度过、幅度不过**的片子，观感就是"一直在动，但不像在打"——这正是第三次实测的失败形态。两者都过，还要看受力对不对（[动作与受力语法](action-craft.md)）。

**镜头运动会污染读数。** 运动能量测的是"整幅画面的变化量"，镜头自己在横移或推进，读数就上去了，哪怕画面里的人在站着不动。**这是一条会让测量失效的漏洞，必须防住两种做法**：

1. **写稿时留采样段**：在动作片里安排一到两拍使用**固定机位**（港片本来就大量用固定广角看人在窄巷里打）。读数落在这些段上才是干净的——镜头没动，变化全部来自人。
2. **读数据时先看转场**：如果全片最高点出现在某个场景切换的瞬间，那不是动作，是切镜造成的整幅变化。这种情况要把该帧排除，再看真正的动作段峰值。

**边界**：这些数值只能判断"动得够不够"，不能判断"打得对不对"。动作的受力、方向、接触点仍需按[动作与受力语法](action-craft.md)看画面核对。低速区间也可能是刻意的（比如情感戏的长镜头），此时不适用本册判据——**本册只适用于"应该一直在动"的类型**。
