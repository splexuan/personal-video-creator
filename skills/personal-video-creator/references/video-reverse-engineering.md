# 视频逆向与复刻

用于用户提供具体视频，要求反推可用于生成的提示词、参考素材，或保留镜头与动作并替换人物。目标是根据可观察画面重建生成方案；不能声称恢复了不可见的原始提示词。只借鉴风格、只评片或只改已有文字时，不强制运行整套流程。

## 先确定当次交付与输入

优先沿用用户已明确的目标、平台、人物与删改要求。用户要一条完整提示词时，主交付就是可整段复制的正文，不能只给逐镜文件、长报告或下载目录。需要参考图时一并给可用图片及一句上传说明。已请求素材包、逐镜生成或首尾帧时，再交付相应文件；分析复杂度不等于用户必须接收复杂目录。

确认生成时实际会上传什么：原视频、原片抽帧、新人物参考图、服装图，还是一张整合后的图。素材够用就继续，不例行询问全部参数。提示词只能引用这次实际上传的素材；原片仅供分析、生成时不上传，就把动作、摄影、节奏和转场写进正文。

## 1. 建立画面与时间证据

- 找到并实际读取视频文件；历史会话或临时附件路径不保证当前可访问。不能只凭文件名、上一轮概述或自己写过的稿件声称已经看片。拿不到视频时明确缺少的内容，保留可独立完成的工作。
- 读取真实时长、画幅、分辨率、帧率与音轨情况。区分容器时长、视频轨时长和最后一帧时间，避免将后期导出规格误当作生成模型参数。
- 先用覆盖全片的抽帧概览确定阶段，再对关键动作、换装、遮挡前后和结尾加密检查。用可用的连续播放补充运动判断；仅看抽帧时注明范围，不把相邻静帧当成已核对完整运动。
- 区分真正硬切、同一连续镜头中的状态变化，以及为生成方便划分的段落。自动场景检测、帧差和颜色变化只用于定位候选点，不能独立证明切镜。
- 后期需要精确拼接时记录帧边界；固定帧率可使用从零开始、入点包含而出点不包含的区间。可变帧率按真实时间戳，不能直接套帧号除以平均帧率。生成稿的时间段是节奏目标，不宣称模型会逐帧照做。

音轨存在、已提取或有波形不等于听过。音乐名、对白、BPM、重拍和同步只在实际听审或分析后写为原片事实；新写的声音方案明确属于创作安排。

## 2. 记录变化与转场机制

按本片追踪必要的固定项与可变项：人物身份、发型、服装、鞋包、道具持有者、朝向、手部占用、空间装置、摄影位置和结束状态。相似服装或短暂遮挡容易漏数，先核对每个阶段，不用一个代表截图推断全片。

一个可执行段落应说明：起态 → 可见动作或材质变化 → 镜头路径与遮挡 → 末态及下一段怎样接上。超现实换装尤其写清材料从哪里开始、沿哪条路径覆盖、旧衣物如何退出、新配件何时出现，以及遮挡移开后应露出什么。不能仅用“炫酷变装”“无缝转场”代替机制，也不把遮挡视为任意改变身体和道具位置的许可。

区分画面叠加的作者标识、独立黑底片尾与衣物固有印花。按用户意图决定保留、替换或删除，不能因原片存在就默认写入新稿，也不能未经要求一律去字。删除片尾后重算结束点与时长；同时检查全片叠加标识、尾卡文字和相邻收尾句，避免只删局部留下冲突。原图上的烧入文字不会因为提示词要求无字就被实际移除，必要时准备干净参考图。

## 3. 只制作必要的参考素材

| 素材 | 控制内容 | 常见误用 |
| --- | --- | --- |
| 人物肖像或多角度图 | 脸、发型、比例等指定身份特征 | 顺便继承不需要的衣服，或沿用旧人物发型 |
| 服装图或多造型板 | 各套衣物、鞋包和出现顺序 | 把不同列生成为多人同框、混搭或分屏视频 |
| 原片关键帧 | 已观察到的构图、造型与状态 | 把原作者标识带进新图，或以模糊、严重遮挡帧锁定人脸 |
| 首尾帧 | 当前一段的具体起态与末态 | 把普通造型拼图指定为首帧，或把未发生的后续状态当作已接受结果 |
| 视频参考 | 明确指定的动作、运镜或节奏 | 在只上传图片的模式里仍依赖原视频，或让运动来源覆盖新人物身份 |

关键参考帧优先清晰、少遮挡且能看见所需细节。并非每次都需要多角度图、每镜首尾帧或大量抽帧；缺少哪项关键控制才补哪项。

用户要求替换人物并只上传一张图时，可把新人物与所需造型整合成一张参考板。生图明确分配“新图控制身份，旧图控制服装”，保留用户指定的脸和发型，去掉旧人物的身份特征；避免将新身份图原本的衣服误带入。调用可用生图能力后实际查看结果，核对脸、发型、套数、鞋包、裁切和文字。生成图是重建素材，不能当作原片证据或声称服装细节逐像素一致。

提示词在靠前位置说明图中多列是同一人物的不同造型、从左到右的使用顺序，以及只参考身份与服装、不沿用拼图构图。若生成入口区分参考与首帧，将造型板用于参考；仅支持首帧的入口更适合准备单人单场景开场图。

## 4. 编译为一条完整提示词

保留必要信息：实际素材职责与身份锁定、整体空间和风格、按时间排列的动作与镜头、转换起止、收尾，以及有依据的声音安排。参考图已能看清的静态细节可适当压缩，把篇幅留给图片无法表达的运动和变化。用户要求细致稿时给足有效信息，不用重复形容词或通用禁令凑篇幅。

平台的参考类型、提示词预算、时长和首尾帧能力以当前实际入口为准；不能把某个平台或 API 的能力套给全部界面。必要时查当前官方资料，不在本技能写死版本上限。用户要一条完整稿时仍先交完整方案；入口确实容纳不了再说明具体差异，按目标压缩或提出分段生成与剪辑方式，不能把完整提示词说成一定能一次生成。

修改人物、参考模式、标识或片尾后，交付修订后的完整正文，并同步更新当次主要参考图与下载文本。不要只给一句替换指令，让用户自己在长稿中寻找旧内容。保留其余已确定的摄影与动作设计，除非修改本身影响衔接。

## 5. 检查、交付与后续学习

交付前执行[提示词自检](prompt-self-check.md)，额外核对：实际上传素材是否与正文一致；人物固定项是否全部更新；每套衣物与配件是否对应；连续段与硬切是否清楚；删除内容是否在全片清干净；时间轴与最终结束画面是否一致。看过新参考图再说图已检查。

素材包按用户需要保存可读提示词、关键图、分镜和剪辑说明。检查链接与文件可打开，必要时检查帧区间无缝隙、无重叠，压缩包完整；这些通过不等于视频生成成功。

拿到多套换装成片后，逐段对照完成态，不能只数“每套都出现过”：

- 区分换装过程和展示阶段。核对旧衣物是否在目标完成点退出、上下装是否均已到位，纤维或布料是否收拢成该套应有的材质；避免将长期残留的旧T恤、短裤、纤维外壳当作已经完成的造型。需要修复时写清转换路径和收束结果，不只增加“生长、蔓延”等过程词。
- 背景与服装一起核对阶段归属。换装后的环绕、背面和回头镜头仍应延续当前环境，旧阶段的道具不能随转身无缘无故重新出现。局部修复时明确当前镜头的背景组合与退出的旧元素。
- 从头核对到结尾，特别检查后半段动作、回顾与最终停留是否实际执行。不要将一套造型停留更久误认作已经完成多套回顾。回顾已出现过的镜头可考虑从可用片段复用剪辑，不必要求模型再次换装重演；用户要一条完整提示词时仍保留完整方案，是否后期完成依据实际入口和需求决定。

时间偏移、转场残留与漏执行要分别记录。一次失败不能证明唯一原因是提示词过长或模型能力不足，也不能证明加更多禁令就会解决；先定位具体段落，修改完成态、摄影、时间容量或剪辑安排，再用新的成片验证。

区分四种状态：原片已观察、文字方案已推演、参考图已检查、新视频效果已验证。只完成前三项时，不能宣称模型复刻、人物稳定、动作还原或音画同步已经成功。拿到新视频后再按[反馈流程](feedback.md)比较关键画面和连续动作，局部修正。

技能只保留可复用的方法、明确偏好与证据边界；外部样片、账号、源文件名、网址及临时本地路径留在当次工作区，不写进技能或成功案例。没有实际生成反馈时，不把交付过的提示词自动记为已验证案例。
