# 动作视觉重音：冲击帧与短促画面变化

用于打斗、格挡、兵器碰撞或明确需要瞬时强调的事件。先确定动作关系和观看重点，再选择效果；不把闪帧当成每条视频或每次攻击的固定配置。

## 让效果依附事件

先写清起势与路径、接触或避让、作用结果及收招接续，再选本场真正值得突出的动作。若重点是反击改变局势，普通交手可以保留正常画面；若重点是险些失败后的格挡，则强调挡住攻击的接触。按戏的目标分配强弱，不固定最后一击才有特效。

提示词交代：具体触发事件、必须看清的对象、画面改变的方式与范围、恢复后的动作。蓄力或出招时的强调不能代替命中证据；接触后的变化也需要先交代攻击确实发生。人物移动、武器路径和后果应能在拿掉效果后仍然成立。

## 选择一种主要处理

| 处理 | 提示词要说明什么 |
| --- | --- |
| 冲击帧 | 接触附近短暂改变造型或画面组织。明确底色、人物轮廓和接触位置；人物之间应能分开。线条可以突出碰撞点、运动方向或姿态，按看点选择，不把三种全部堆上。背景简化只在该瞬间发生。 |
| 闪白 | 区分全画面曝光抬升与接触处发光，后者需指定光源和范围。需要读懂命中时，保留轮廓和关键接触信息；有意使用纯白遮挡时，先交代动作证据并安排恢复。 |
| 反相 | 明确是短促的明暗或色彩翻转，随后回到原有画面。变化期间仍能辨认动作，恢复后人物造型不继承负片色。 |
| 闪黑 | 黑场遮掉所有可见内容，先让关键接触可读，再短暂遮断并接回同一次动作的后果。不能靠黑场把尚未命中的姿态直接跳成远处倒地。 |

效果长短按原速观看的感受与动作容量选择。生成提示词中的精确帧数只是目标，不是执行保证；只有已知帧率时才换算帧数与秒数。效果应结束得足够早，让观众看清接触后果与收招。

组合效果时写明先后、各自作用和恢复终点。第一次设计某段动作可先选一个主效果，避免叠加遮住整条动作链；用户明确要组合时直接按目标设计，不增加审批步骤。

## 原创写法示例

剑修左脚退稳，右手持剑斜架来刃。两剑交会的一瞬，画面变成深蓝底上的浅金轮廓，保留双方握剑手、交叉剑身与接触点，仅在交会处出现少量短线。随即恢复庭院原有色彩；对手剑锋沿架住的剑身滑向外侧，剑修顺势转腕卸力，两人的脚步和武器位置连续。

这个示例强调成功格挡。换成挥剑启动、破盾或其他事件时，重新设计接触对象、视觉焦点与结果，不只替换武器名。

## 自检与成片修复

文本阶段按[提示词自检](prompt-self-check.md)检查触发是否具体、变化是否有结束、接触是否可读、恢复后姿态与方向是否接续，声音是否落在对应事件。为效果分配的时间不能挤掉动作后果。

成片先原速看连贯性，再回看关键位置；按[反馈流程](feedback.md)记录实际观察。提前闪动先核对事件描述；整段风格改变先核对作用范围与恢复；位置或武器突变先修动作衔接；打击无分量先检查接触、受力和回收。必要时简化机位与动作，再试效果。以上都是待复测的修复方向，不将某个现象认定为唯一原因。

比较版本时尽量保留动作和设置，只换效果描述，并检查实际动作是否也变化；不能把一次生成的优劣全归给效果类型。
