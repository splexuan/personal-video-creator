# 视频类型与创作模板

本指南覆盖生活情景及案例库中已出现的其他用途。先按要创作的内容选模板，再按需要叠加画风或制作方法。各类型使用适合当前目标的字段；模板结构可调整，不要求统一模块名称或数量。

## 怎么选

1. 先明确观众应当看懂或感受到什么：关系变化、笑点、产品、服装、音乐、任务或制作过程。
2. 选最接近的一个内容模板；混合故事以主要目标为主，例如骑车广告选广告结构，再借车辆连续性。
3. 按需要选画风与制作方法；“3D 动画 + 反转喜剧”或“产品广告 + 定格”可以组合。
4. 新创作先用[导演设计](directing.md)选择视觉主意、信息顺序和镜头关系，再结合[共用写法](video-core.md)与所选模板组织具体主体、动作、声音与时间。完整稿删除空栏目、无关段落与创作者操作说明。
5. 各模板的字段与段落是可调整的功能，可增删、合并、改名或重排；不固定模块数、镜头数量、时长或画幅。用户给定脚本与要求优先。

## 可叠加的画风与制作方法

| 选项 | 用途 | 补充模板 |
| --- | --- | --- |
| 动画与混合画风 | 2D、3D、定格及真人与贴纸混合 | [补充写法](../assets/modifiers/animation.txt) |
| 复古 DV 与档案影像 | 家庭录像、DV、胶片纪录和旧影像感 | [补充写法](../assets/modifiers/retro-footage.txt) |
| 第一人称与连续长镜头 | POV、自拍、跟随、目击者记录与一镜到底 | [补充写法](../assets/modifiers/continuous-take.txt) |
| 时间冻结、倒放与变速 | 视觉异常、时序喜剧与时间特效 | [补充写法](../assets/modifiers/time-effects.txt) |
| 分镜图驱动与分段衔接 | 已有分镜图、首尾图或需分段的长片 | [补充写法](../assets/modifiers/storyboard-driven.txt) |

补充模板按本片实际结构使用。时间冻结可以单列时间规则，也可并入状态时间线与声音设计；画风可放在视觉方案中。保留有用信息，避免重复总纲。分镜图驱动仅在已有分镜图或明确要求时使用。

## 来源与状态

来源固定为 ZeroLu 案例库和 LearnPrompt 案例数据，整理日期 2026-10-08。

已读 ZeroLu 的 21 条完整记录；LearnPrompt 累计选读 47 条，其中包括两条分镜页生图稿。仅保留类型组织与方法摘要，不收录外部样片或来源网址。研读提示词不等于个人重新生成成功。

这些填写模板是从研读方法整理出的个人创作工具。模板改编的新片仍按[反馈流程](feedback.md)记录实际结果；既有个人案例不因扩充类型而改写。

用户提供的《电影级 AI 舞蹈视频编舞导演》与参考分析提炼的互动表演方法已经整合到[统一舞蹈导演](dance-performance.md)。短独舞与音乐 MV 共用乐句、动作短句、身体力学、表情、衣发响应、摄影和衔接方法，按目标选择模板；平台专用字段按本次实际入口选择。

单人镜头互动、手势舞或短随拍可用[轻量模板](../assets/templates/dance-short.txt)，不强套 MV 的五段结构。外部样片仅供分析，技能保留提炼的创作方法。

单次生成、分段生成、截图衔接和后期拼接是不同制作方式，按本片需要选择；本指南不根据总成片时长推断模型单次生成上限。创作参数依用户与实际入口决定。

具体生活情景的案例方法见[已有研读](external-cases.md)；多类素材分工与逐镜修复见[外部方法](external-methods.md)。

两个导演项目的方法已接入[导演设计](directing.md)：AI Visual Director 用于素材、调度、表演与状态；AI Storyboard Director v5.2 用于视觉主意、信息显露和镜头衔接。它们是共用决策方法，按当前类型使用，不构成新的内容分类或固定提示词格式。
