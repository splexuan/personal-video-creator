# 完整舞蹈编排：短视频表演展示

用于设计整支舞、重做缺少变化的编舞，或把动作方案写成完整舞蹈视频提示词。目标是让舞者完成一段有辨识度、节奏、发展、观看高光和结束关系的表演。与[舞蹈导演](dance-performance.md)共同使用；素材与取景未定时先按[创作准备](dance-preparation.md)推进。

用户不需要成为编舞者。AI 根据风格、人物、造型、音乐、时长和画幅主动选择动作材料，承担编排与取舍；通常直接交付所需视频稿。用户只改一个动作、只要局部手势或已有明确完整舞谱时，保留其范围，不擅自重编整支舞。

## 从整支舞到动作细节

先确定整支舞的观看效果，再选动作短句和它们的关系，最后落实身体、表情、衣发与摄影。以下是内部设计依据，可合并或调整顺序，不要求用户逐项审批，也不要求成稿使用固定栏目。

| 层次 | 要确定的内容 | 可交付的依据 |
| --- | --- | --- |
| 整体表演 | 本片让人记住什么，情绪和能量怎样变化，最值得看的时刻在哪里，最后怎样结束 | 一句话能描述主要看点与发展，段落各有作用，时长有足够动作材料支撑 |
| 动作短句 | 主要动作、对比动作、重复与变奏、段落过渡及音乐落点 | 能辨认的运动路径、节奏和轮廓；前后既有关联，也有观众可见的变化 |
| 实际执行 | 朝向、承重、起止状态、动作容量、手脚边界、表情与衣发响应、机位与声音 | 各时间段写出可执行行为，关键看点能被所选构图看见，素材与音频要求有实际依据 |

舞种或风格只给一个宽泛标签时，选择清楚的主要动作语言。例如“国风柔美”需要进一步落实为躯干与手臂的流动、直线穿出、侧面拧转、呼吸伸展等本片具体材料；“热舞”需要明确主要身体焦点、律动、发力和动作轮廓。用户已指定动作语言时沿用，不把某种服装自动等同于一种编舞。

## 开场、发展、高光与结束怎样完整

这些是表演功能，数量、顺序与持续时间随本片选择。短视频可以将多个功能合在一个短句里；持续律动、极简或循环舞也能完整，不要求先慢后快、固定五段或每段切镜。

| 表演功能 | 在当前舞里怎样体现 |
| --- | --- |
| 建立看点 | 在开头可用时间内出现辨识度或节奏感，不把主要看点全部留到很晚；开场姿态直接为动作启动服务 |
| 发展材料 | 通过同一短句的变奏或有关系的新材料，让动作继续发展；重复可以强调主题，延伸可以展示身体线条 |
| 形成对比 | 在适合当前风格的位置改变动作质感、身体焦点、空间或节奏，让观众明确感到一段变化 |
| 产生高光 | 一个经过前段铺垫、能被看见的动作事件或短句；可以用力度、突然安静、方向变化、完整造型或动作与衣发的错时形成重点 |
| 完成结尾 | 回应主动作、完成当前动量、落在最后音乐或继续进入循环；结束状态与前面有关，保留必要的回收和余摆 |

可以先给高光，再发展并以变奏回到它；也可以从简洁律动逐渐展开，或以两种材料交替形成层次。按音乐和观看目标选，不能只把一串同类动作标成“起、承、转、合”就认为结构完整。

用户指定较长时长时，用材料发展、节奏对比、主句重现、空间或身体焦点变化支撑长度。连续伸展或停留是否延长，由本片观看效果和音乐决定。若材料不足，优先发展编舞；时长可调整时可以建议压缩，用户已固定时长则完成该时长的设计，不用机械减速和反复回收填满。

## 设计一个可记住的动作短句

为完整的舞蹈展示选择一个主要记忆点，通常是简短而有辨识度的动作组合；它也可以是持续律动中的节奏轮廓、舞者与摄影的互动或明确的身体图形。根据本片风格选择，不强制每支舞都重复同一手势、旋转或靠近镜头。

一个动作短句需要能说清：从什么状态出发，哪个身体部位先动，路径与朝向怎样变化，节奏长短怎样组织，最终落在哪里。只说“漂亮、有节奏、有记忆点”不构成实际设计。

重复发展时，保留足够的核心轮廓、路径或节奏，让观众认得出来，再有目的地改变方向、朝向、幅度、速度、身体焦点或层次。改变全部属性可能失去关联；完全同速同幅复做又可能显得机械。重现次数由音乐和容量决定，不按固定次数凑时长。

例如，国风半身可以用“直线穿出 → 手腕交叉一次 → 双臂形成一高一低斜线 → 拧身与目光落定”的轮廓作主句；后段换侧或转成侧面，保留识别点。这里仅示意短句的组织，不是默认动作或已验证成片；开场和过渡仍依据当前姿态设计。

## 段落区别要让观众看得见

比较相邻段落时看实际运动，不看标题与形容词数量。以下维度按本片择用，不要求每段全部变化，也不为差异破坏同一舞种的语言。

| 维度 | 可见的变化 | 容易显得相同的写法 |
| --- | --- | --- |
| 身体焦点 | 手臂线条转为躯干转向、重心落点、肩髋配合或完整步法 | 每段都是抬手、绕腕、回收到胸前 |
| 动作路径与轮廓 | 圆弧与直线、交叉与错落、紧凑与开阔、对称与非对称 | 只把同一手臂弧线换到另一侧，节奏和形状几乎不变 |
| 朝向与空间 | 正面与侧面、前后纵深、小范围移动或队形发展 | 始终正面附近，只有非常细微的转头和摆腰 |
| 高低与幅度 | 受控下沉与舒长、局部动作与整体展开、不同高度的手位 | 全程同一高度与范围，最强段只是再多伸一点 |
| 动作质感 | 快发慢收、持续延伸、短促落点、回弹、悬停或释放 | 全程缓缓、柔和、顺势，所有段落同样减速 |
| 节奏密度 | 短动作与长动作交替、重音与回收、持续律动中改变重音位置 | 只有“速度变快”的说明，没有具体节奏变化和动作落点 |

有意重复的主句与承担对比的新材料分别安排。原地舞或手势舞同样可以借轮廓、朝向、时值与力度发展，不因为空间有限就只剩手腕变化。云手、画弧和伸展可作为风格材料；出现反复同质时检查整支舞的材料与功能分配，而不是一律禁用这些动作。

## 柔美气质与清楚节奏怎样兼容

将柔美落实在动作线条、呼吸、延伸与控制中，同时决定哪里短促、哪里延长、哪里强调、哪里回收。快速动作可以轻而准确，短停可以保留呼吸与衣发余摆，强度无需始终最大。

例如快速穿出后延长斜线、连续流动后受控停点、躯干先转而目光稍后回到镜头，都能在同一柔美风格中建立节奏。不同舞种可采用其他材料；不把“短—短—长—停”变成所有舞蹈的统一节奏。

已有音频时，根据实际使用片段确定重音、延长、转折和结束，再把身体动作映射过去。没有音频时，先给拟定的节奏关系、段落密度与动作重音，标为可调整设计；乐器从古筝换到琵琶或配器逐渐增加，本身不能替代动作的节奏组织。未经听审不声明精准同步、真实 BPM 或确定拍点。

## 高光如何产生视觉冲击

写一个具体、可辨认的变化及它与前段的关系。比如收紧之后展开、连续流动之后停住、平面线条转为纵深、原地短句转入有方向的行进，或身体落定后衣发继续运动。按风格选择效果，舞者的控制与看点可读优先；不通过不断增加动作数量、跳跃、旋转、甩头或剧烈运镜统一制造高光。

“最开阔、最有冲击、全片高潮”后面要有对应行为：实际怎样改变轮廓、方向、速度或身体状态，观众为何能看见。高潮可以短而集中，也可以由一个持续发展完成，不必全程最高能量。镜头在关键动作时保持可读性；音乐、舞者、摄影同时变化时明确主要看点。

与摄影机互动可以是本片记忆点，保留实际的引导动作、空间变化和表情回应；舞蹈展示主导时，亲近镜头、浅笑与手部互动不能无故占据整段而让身体表演消失。互动时也可以维持本片律动或由主句发展出动作。

## 构图与动作容量

半身主要使用上半身的轮廓、朝向、纵深、节奏和可见重心变化；七分身可明确膝部参与；全身用于重要步法、行进与接地。只在脚步确实是观看重点时要求它可见，半身中的脚下支撑仍需可信。相应的图片准备见[取景选择](dance-preparation.md#半身七分身还是全身)。

9:16 中人物较大的半身构图与双臂水平完全伸直、完整双手同时入画可能冲突。按实际动作选择弯肘、斜线、前后纵深展开，或连续放宽景别；不能同时保留过紧边界和过宽动作。主句与高光先检查最大动作范围，再准备首帧和摄影路径。一镜到底、固定机位也能容纳编舞层次，不靠新增切镜掩盖材料单一。

安排每段容量时，保留启动、主要运动、落点、回收和过渡。多次换向、转身、落脚或摄影推退各有完成时间；姿态停留有音乐或观看作用。高密度材料中仍能辨认主句，安静段仍是有意表演；不把动作数量与时长机械相乘。

## 写入提示词与交付检查

将整支舞的决定写入当前模板或连续时间线。先有简短总纲，说明主要看点、主句与发展，再在各时间段写实际路径、节奏、重心、表情、衣发、摄影和末态。设计中的字母代号、备选方向与无内容的功能名称不能代替生成所需的具体行为。复杂方案可先展示精简编排，用户直接要最终稿时直接完成。

交付前依据当前目标检查：

- 开头是否及时出现本片主要看点，主动作是否能被说清并看见。
- 段落发展是否有可读区别；重复是否有识别点与变奏依据，转折是否由实际动作承担。
- 节奏是否落实为长短、轻重、启动、落点与回收；连续柔美是否仍有本片需要的层次。
- 高光与前段相比具体改变了什么，镜头是否完整保留关键动作。
- 最后状态是否回应前段或完成当前运动，循环是否有真正接续条件。
- 图像、身体、音乐、时长和构图要求是否相容，未检查的音频或未生成效果是否被误写为已验证。

修复动作同质时，暂时去掉运镜、音乐和“柔美、流畅、惊艳”等形容词，概括各段身体行为。若多数只剩相同的展开、回收与转腰，应重新选择材料、节奏或段落功能。修复的是可见编排，不能只增加“丰富变化”或“禁止重复”的要求。

这些标准用于本次需要的完整舞蹈展示；极简、重复性舞种或用户指定单一动作按其目标保留相应设计。实际效果继续依据[反馈流程](feedback.md)记录；文字方案的完整性不等于生成已成功。
