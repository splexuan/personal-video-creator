# 机位可行性与冲击预算

用于判断"这个调度模型做不做得到"和"这一下该不该给重音"。与[动作与受力语法](action-craft.md)、[动作视觉重音](impact-frames.md)、[摄影与画面设计](cinematography.md)及[共用写法](video-core.md)配合。

**这一册解决的问题是：稿子读起来没问题，成片却翻了。**原因常常不是写得不够细，而是用了一个模型做不到的机位，或者把重音平摊到每一击上。

---

## 一、机位可行性黑白名单

左列是**默认禁用**的高风险调度。要用它，就得同时写上右列的安全替代，或者改用分段产线。

| 高风险调度（默认禁用） | 失败表现 | 安全替代（默认写法） |
| --- | --- | --- |
| 镜头绕弧 180° 加一方高速掠过停到另一方身后 | 主客颠倒：掠过者在变前景的瞬间定格，另一人蹲在他身后，观感滑稽 | 正侧面固定机位、两人同向侧影；或掠过者停在后半步，镜头不越轴 |
| 脱手武器旋转飞出、插到远处 | 小物体消失或原地竖立 | 武器朝屏幕指定方向脱手，**全程在画**，1 秒内落入画面内地面并弹一下停住，给尺寸参照 |
| 同帧双向高速交叉后要求精确落点 | 位置重置、朝向错乱 | 交叉后半秒同向滑行减速，再分别停住，用锚点重新定向 |
| 长时长垂直穿层后精确返回开场点 | 模型新造场景、硬切回地面 | 穿层后不回场，在新一层收束；要回场必须分段 |
| 一镜到底中 360° 环绕同时读手部细节 | 方位丢失、穿模 | 环绕不超过 180°；手部信息另给固定特写镜，用遮挡衔接 |
| 急推同时要求主体距离不变、一拍内环绕加推镜加变焦 | 镜头矛盾、主体变形 | **一拍一个主运镜**；复合运镜拆成相邻两拍 |
| 长时间灰雾或黑场过渡 | 近 1 秒空帧、叙事中断 | 遮挡满画 ≤1 秒，遮挡中保留运动残影或掠过物轮廓 |
| 完美圆形或环形敌阵把主角围在正中、主角抬武器定格 | 对称 tableau 凝固约 3 秒，像群演摆拍 | 不对称流动人潮：前方厚、两侧薄、潮线持续移动，主角沿缺口边走边打；唯一环形技能 0.8 秒内放完，不摆造型 |
| 连续大远景、角色立于对称构图正中 | 成片像静态原画，远景之间只能硬切 | 30 秒群战大远景 ≤3 个、每个远景内部有强运动，其余为贴人移动的全景或中景 |
| 收尾只写"胜者站立、败者跪地"、镜头停住 | 模型默认拍成正面居高临下的 3 秒静态胜利摆拍 | 最后 1–2 秒镜头持续后拉或横移，两人保留余动（喘息、衣发飘动、水面余动、武器微颤），静止造型不超过 1 秒；机位写侧后方或正侧面，避开它最熟悉的正面定格图式 |
| 双人同高度静止对轰、两堵特效墙相持 | 连续数秒相同构图，交界无推移，读不出胜负 | 高低错位加运动中施法；相撞后 1.5 秒内按"裂纹→推移→碎裂→触身"带过。细则见[动作与受力语法](action-craft.md#九群体战与对轰) |
| 终局龙凤或双兽对轰、施法者被自己的构造裹在中间 | 自己困自己，爆炸像自伤，胜负读不清 | 大型构造始终在体外朝向对手；护体只留贴身薄层、不形成球罩；最后一击写明构造触及败者身体，接触点与归属同句交代 |
| 结尾败者跪地、胜者立于标志物两侧 | 对称静态站位被持续数秒，像舞台造型 | 结尾保持运动：败者滑退、翻滚、挣扎起身失败或借烟尘逃走，胜者迈步追击或追一步停住，镜头横移或后拉到最后一帧 |

**通用安全原则**：越轴必须用可见的连续绕行交代；末帧优先侧面或背面中景，不要求角色正对镜头；决胜后给呼吸、余动、未收回的武器与未平息的环境，不摆胜利姿势。

## 二、遮挡转场

隐形切镜与分段拼接的首选衔接。**用法**：遮挡物在动作趋势中自然掠满画面（≤1 秒），切后延续六字段状态（位置、朝向、距离、动量、伤损或资源、握持）。

- **身体类**：交手双方身体掠过、披风或旗帜、敌群个体冲镜、载具外壳。
- **介质类**：云雾、水花、烟尘、爆光、火焰、雪幕、能量幕。
- **结构类**：柱、门框、桁架、墙体、廊柱、树干。
- **暗场**：冲击帧白闪或黑场，全片配额见下节，不可连续使用。

**切镜纪律**：切点接在动作趋势上；切后第一帧交代位置与朝向；**每镜一个叙事目的**（建立空间、展示威胁、读出攻防、释放重击、呈现结果，五择一）。

### 满画遮挡要按量写

"遮满画面"极易被模型照字面执行成整屏水墙、白屏或近一秒黑糊（外部来源标注为实测）。直出版默认让遮挡物**横划掠过、遮住约三分之二画幅**，画面边缘保留主体运动轮廓或前景物——木板横划、芦苇扫镜、身体局部掠过。确需满画只给 0.3–0.5 秒并保留掠过物的运动残影，**同一段满画遮挡不超过一次**。

## 三、冲击力表达预算

重音要**按片子类型配额**，不是每击都上。平摊的结果是每个镜头都用力，最后记住的接近零。

| 片子类型 | 允许的重音 |
| --- | --- |
| 写实片 | **不用白闪与升格**，只用接触前极短停顿、接触后受控短震与随势拉镜 |
| 一张一弛片（回合决胜） | 冲击帧全片 ≤1 次、短促升格全片 ≤1 次，都只给决胜；蓄力段是全片最低速点，反推是全片最高速点 |
| 全程实时高速片 | **禁用 hit-stop 与长慢动作**，仅终局允许一次不超过 0.3 秒的极短微停 |

高速片的冲击靠六件事：亮度脉冲、速度突变、镜头急推与受控短震、环形空间冲击波、环境反馈、受力方位移。

### 短促升格只拍命中那一瞬

升格容易变成定格摆拍。写法（外部来源标注为实测）：**升格只覆盖命中接触的那一瞬，屏内约 0.3–0.5 秒，写明"命中瞬间慢放半秒，一蹬实立刻回实时"**；受力者的倒飞、犁地、撞落、缓冲**全部在实时速度中完成，慢放段不承载位移全过程**。

升格前一镜必须交代飞退方向有空场（见[动作与受力语法](action-craft.md#受力方向必须有空场)）：踢击点选开阔处、身后不留紧贴障碍，落点障碍放在飞行路径前方而不是起点身后。

用户明确要求受力特写升格时，全片至多一次。

### 因果顺序

**命中先于震动、音效、冲击帧和受力后果。**音乐卡点对齐接触或反转，不给每个鼓点强塞一招。

## 四、单段直出能力框

单段文生视频（尤其无参考图时）的可靠区间。**超出区间不是"写得再详细点"能解决的**，必须走下一节的产线规则。

1. 时长内主要区域 **≤3–4 个**；新区域、新地标、新敌人类型只允许在前 60% 时长引入，**后 40% 不得出现任何新场景元素**，只能回到已建立的区域。
2. 需要观众记住的有名角色 ≤2；群体以统一材质的波次存在；需要记住的小道具 ≤1–2 件，且在前 2 秒给出清晰特写。
3. **前 2 秒必须完成**：主锚点入画、力量关系可读；冷开场时第一次接触已经发生。
4. 高风险调度默认禁用，替代写法见第一节。
5. 高风险空间：先在介质之下、穿出到介质之上、再俯瞰原点俯冲返回的三段垂直调度，单段直出只给简化版，完整版必须分段。
6. 事件密度：决胜段（最后约 3 秒）主要动作 ≤3 个；全屏特效单次持续 ≤1 秒；同一画面能量色 ≤2 系；接触点不被特效遮挡。
7. 无参考图时，角色面部、特殊武器、面具在长时长尾部必然漂移——对策是**自动产出资产图提示词**（见下节），不是要求用户自行补图。
8. 受力几何：每个击退、踢飞、撞落写明"起点—飞行距离—落点"，三者不得重合。细则见[动作与受力语法](action-craft.md#受力方向必须有空场)。
9. 遮挡与特效时长：直出版遮挡默认不超过三分之二画幅，满画 ≤0.5 秒、每段一次。**全屏特效单次 ≤1 秒，时长上限直接写进该镜头句子**（如"爆光 0.8 秒后迅速收束，只剩接触点残弧"）。不设"铺满画面 1.5–2 秒"的例外；用户要大场面时靠构造数量、粒子层次与镜头运动表现，不靠全屏长亮。爆光中接触点与两人轮廓必须可读。

## 五、两条产线

**产线 A｜省事直出。**结构在能力框内时直接给单段提示词。超出能力框时**自动降级**，不把超纲结构丢给模型：

区域合并到 ≤3–4 个；闭环往返改单向流动；垂直穿层改单层调度；绕弧换位改固定侧面机位；跨画面脱手改近身缴械（武器落在画面内可见处）；后半段新元素前移到前 60% 或删除；群体规模按可读密度而非数量词控制。交付时用一句话注明做了哪些降级。

**产线 B｜高保真分段。**用户要完整奇观、多区域、复杂垂直调度时，自动产出分段包：每段 **5–7 秒**（**不得少于平台单次生成下限 4 秒**，见[平台口径](platform-notes.md#七时长分辨率与入口)）；每段含**承接状态行**（上段尾帧的六字段）、本段动作、重复绑定的资产清单。段数由波段与成本表算出，不由固定模板决定。

两点针对动作类片子的调整（见[动作密度与节奏](pacing.md)）：

- **不必每段都设遮挡尾帧。** 遮挡尾帧是为了在**单段之内**做隐形切镜；分段生成时，段与段之间本来就是生成边界，再要求每段都以一次遮挡收尾，等于逐段插入一次停顿仪式，节奏会被切碎。
- **段间接续改用"切在动作六到八成处"（cut on action）**：这一段的描述结束在动作还在进行的那一帧（"切在他刚踩上筐、身体刚开始前倾的那一帧"），下一段以"承接动量"开头（"他正在向前扑"）。这样接出来的是连续动作，不是一组完整的起手与收手。

**默认交付规则**：20 秒以上或命中任一高风险项时，同时给直出版（已注明降级）与分段版（高保真），一句话说明差异；用户明确只要其一则遵从。**但交付时要说明成本顺序**：直出版是**一次生成**，分段版是**按段数次生成**。因此默认执行顺序是先跑直出版，出片后核对，只在某一段出问题时用 Extend 或视频编辑**局部补**，不要整片重生成、也不要两版同时跑。用户明确关心生成成本时，这一条要写在交付最前面。

**资产图提示词**：纯文生且没有角色、武器、场景参考图时，自动附带可直接用于文生图的资产提示词（角色三视图、专属武器、主场景，一主体一条，建议竖版 3:4），作为标准附件，不向用户收取额外工序。
