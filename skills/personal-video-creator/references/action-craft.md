# 动作与受力语法

用于打斗、追逐、群战、冲撞等以身体和器械对抗为主体的片子。与[动作模板](../assets/templates/action.txt)、[动作视觉重音](impact-frames.md)、[摄影与画面设计](cinematography.md)及[共用写法](video-core.md)配合；机位与时间预算见[机位可行性与冲击预算](camera-feasibility.md)。

**这一册解决的是"打斗像不像真的"**，不是"打斗好不好看"。好看由[创意发散](creative-divergence.md)的机制和摄影决定；这里管的是物理因果——谁发力、往哪打、有没有碰到、受力后怎样。没有这层，再华丽的特效也是两团光在乱撞。

**"打斗够不够快"是第三件事，单独由[动作密度与节奏](pacing.md)负责。**三者的分工：密度定一秒里发生几件事，受力定每件事对不对，摄影定它好不好看。**密度不达标时，受力写得再准也救不回来**——成片会变成一组精致的静态照片。写这类片子先读 pacing.md 定单元总数，再回来写这里的受力。

## 〇、写这一册之前先过一遍的四条（详见[动作密度与节奏](pacing.md)）

1. **持物必带位移轨迹。**"抱住／举起／端起／握住"只是状态，会被渲染成静态姿态；必须写出从哪一点移动到哪一点、经过哪条路径。
2. **情绪与痛感写在动作里。**不写"愣住、抬头看、站定、对峙、停下喘气"；改成"视线偏了一下、脚已经在往侧后方撤"。
3. **承接动量不许归零。**每一段末尾必须有人正在往某个方向运动，不写"站稳／收势／动量近零"。
4. **节奏的"顿"写成"换一种运动"**（脱手飞起、翻身跌落、东西滚过去），绝不写"极短停顿／凝住"。

## 一、动作状态链（七拍）

每个主要交锋都要走完七拍，缺哪拍就在提示词里补上：

`当前位置与支撑 → 发力或启动 → 攻击轨迹与目标 → 对手应对 → 接触或落空 → 受力结果 → 下一拍可用姿态`

- **明确谁发动、谁接招。**双人场景少用连续的"他/她/对方"，直接用角色名或 A、B，否则模型分不清谁在动。
- **动作衔接以重心、惯性和距离为依据。**脚落地才能重新蹬地；单脚支撑时另一条腿才可完成踢击；起跳有起点、弧线与落点。
- **腾空必须有可见来源。**御剑、法阵、推进器、姿态喷口、缆索、蹬碎的支点——写明是哪一个。无来源的悬浮、踏空、空中自由转向是最常见的翻车点。
- **写清命中、被挡、擦过还是完全落空。**同一击不能既被闪开又出现命中效果。对手在威胁出现后才防守，在受力后才退移。
- **兵器要写归属与几何。**谁握、哪只手握、刃尖朝哪、碰在哪里；换手、脱手、断裂与再取回必须发生在画面里。
- **距离由步法或位移改变**，不把远处的角色瞬间塞到近身；击退多远就留相应的追击与飞行时间。
- **失败动作必须存在。**攻击被挡、反击落空、冲撞被架停——它们制造真实感和均势感。全程只有一方得手，出来的就是木桩戏。

## 二、受力反馈四通道与尺度分级

放弃"快速出拳、猛烈踢腿"这类抽象写法，改描述蓄力、受力、反馈和状态。**每次关键重击从下面四通道里选 2–3 项**，不要每样都来：

1. **身体**：守势压缩、肩背随力转动、后脚补步、重心失衡、空中姿态、落地缓冲与滚动。
2. **物体与环境**：护甲凹陷、剑身振动、积水沿力向溅出、鞋底推出尘土与沟痕、接触处碎片崩落。断裂方向服从受力方向。
3. **镜头与时间**：接触前极短停顿、命中瞬间冲击帧、受控短震、关键一击短促升格、击退后随势拉镜再回常速。配额见[机位可行性与冲击预算](camera-feasibility.md#三冲击力表达预算)。
4. **声音**：挥动破风 → 接触瞬间材质声与低频 → 余振 → 落地声。因果顺序不能错位。**命中先于震动、音效、冲击帧和受力后果。**

### 尺度分级

夸张程度服从力量体系。同一场戏里，受力表现与环境响应上限要跟着主体尺度走：

| 尺度 | 代表主体 | 受力表现 | 环境响应上限 |
| --- | --- | --- | --- |
| 凡人 | 拳手、士兵、枪手 | 踉跄、滑步、单膝跪地 | 水痕、尘线、木器开裂 |
| 武者 | 武侠高手、强化士兵 | 贴地滑行、撞裂木石 | 柱断、墙塌、气劲掀物 |
| 修士／超能者 | 仙侠主角、异能者 | 凌空击退、穿破建筑、沿地面犁出深沟 | 石台崩碎、山体缺口、云海被冲开 |
| 动力装甲／轻型机甲 | 人形战甲、外骨骼 | 推进偏移、装甲凹陷、关节过载 | 甲板凹陷、掩体破裂、尾焰与碎屑沿矢量扩散 |
| 巨兽／重型机甲 | 妖兽、魔像、重型机体 | 多足撑地仍被推动、结构件变形、机械迟滞 | 地面龟裂、步震、烟尘柱 |
| 群体波次 | 魔潮、虫群、无人机群 | 密度空缺、编队缺口、单位沿力向爆散 | 覆盖物被犁出空带、堆积物位移 |

**材质响应必须匹配。**裸拳与布料不出金属火花；冷兵器交击可有短促金属音与少量火星；法术或能量对撞出光爆、冲击波与粒子，不是电焊火花；水花与尘屑不跨场景自动添加。非接触震飞要写明冲击波或气劲**何时到达、如何传播**。

**通常只突出一至两个"英雄重击"**，小动作轻、决定性攻击重。

### 受力方向必须有空场

写击退、踢飞、撞落之前，先检查受力者当前的位置和飞退方向——**如果身后紧贴巨石、墙沿、崖边，就不能再写"倒飞撞上该障碍"**。起点与落点重合时，模型会把人物定在原地拍成静态造型（外部来源标注为实测）。

落点障碍放在飞行路径**前方**，写明飞行距离与缓冲。起点已无空场时，先安排一个位移波段把人打到开阔处，再给重击。

## 三、反馈链目录

均势战斗的最小单位是**反馈链**，不是单次交锋。从下列单元拼接，相邻单元不重复：

- 格挡 → 偏转刃线 → 侧闪 → 反攻
- 攻击 → 对方卸力 → 借力变向 → 追击
- 高速碰撞 → 双向弹开 → 重新追击
- 佯攻 → 封死退路 → 命中
- 远程压制 → 对方掩体换位 → 突进缩短距离
- 冲撞 → 被架停 → 角力 → 一方支点破坏 → 推开
- 被连击压制 → 一次成功防御 → 打断对方节奏 → 抢回攻击角度
- 合围收缩 → 一次范围手段打出缺口 → 向缺口突围
- 救援：被围者受压 → 救场从明确方向切入 → 双方视线或弹道关系交代 → 合流后分工

**均势要求**：双方主动发起次数大致等量；任何一方不连续当木桩超过一个波段；追逐战中追逐方必须在追逐中出招。

## 四、空间调度语法

每个调度单元都要写清：起点位置、路径与方向、支点或动力来源、过程中的前景参照、落点与落后面向。

| 调度 | 必须写清 |
| --- | --- |
| 接近／冲刺 | 初始距离、缩短路径、步法或推进方式、前景视差；到达后才有近身动作 |
| 交错／擦身 | 谁从谁的哪一侧掠过、掠过后各自朝向与屏幕位置；交错瞬间可埋一次交换 |
| 爬升／升空 | 每一层高度的支点、上升弧线、高度参照物；禁止无支点连续腾空与垂直漂浮 |
| 坠落／俯冲 | 朝向、前景高速掠过物、加速参照、接地缓冲；坠落中交手要写身体朝向如何改变 |
| 追逐 | 前后位置如何变化、路径收窄或障碍、速度参照物；追逐必须有终点 |
| 合围 | 包围方向数、压力如何收缩、缺口在哪、被围者的近失；合围是动态收缩，不是站成一圈 |
| 突围／救场切入 | 缺口或外力从哪个方向来、被围者与救场者的视线关系、合流后的分工与背靠背方位 |
| 弹道／投射物 | 发射源 → 传播（尾迹、掠过物、先后顺序）→ 与护盾或目标相遇 → 响应 → 余态 |

**禁止"发射源一亮，远处同时爆炸"。**

### 介质层穿越三段式

云、烟、雾、水、火幕、沙暴、能量幕共用同一套写法，**必须按三段写**——这是高翻车点：

1. **先写介质几何**：介质是水平铺展的层（云海、湖面）还是竖立的墙（烟墙、瀑布、火幕）；人物当前在介质的哪一侧；介质边界在哪里。
2. **穿入**：人物从明确方向进入，介质被撕开或排开（写排开方向），画面被介质短暂遮满 0.3–1 秒作为转场。
3. **穿出**：露出新一侧的空间关系——若到了介质上方，镜头必须朝下看见介质表面与人物高度的关系；用一两个已建立的锚点重新定向。

红线：

- **禁止把介质写成漩涡、涡眼、对称双涡、传送门、竖立云墙、环形空洞**（除非剧情明确就是传送门）。"空洞"只能写为冲击波造成的瞬时回弹凹陷，不写持续张开的洞。
- 禁止人物停在介质前静止悬浮；禁止只写"到达云层上方"而不写穿越过程。
- "穿到介质之上再俯瞰原点俯冲返回"是三段垂直调度，超出单段直出能力框，直出版只写单层穿越，完整版走分段。

## 五、能力与武器系统生命周期

超现实或高科技战斗先声明力的来源。每个技能、武器或防御系统**六步齐全**：

`能力积聚在已指定部位或器物 → 动作引导能量沿单一主轨迹释放 → 传播（尾迹、粒子、被照亮的环境）→ 与对手力量相遇或命中目标（接触点清晰）→ 身体与环境响应 → 衰减消散、战果显露`

科幻等价链：`反应堆／电容／弹仓就绪 → 炮口或执行器引导释放 → 弹体或光束沿可读矢量传播 → 与护盾或装甲相遇 → 后坐、热量、结构响应 → 冷却、耗散、资源状态进入下一拍`

### 对波与对冲

`蓄力 → 轰出 → 相遇（交界线落在画面可读位置）→ 拉锯（交界线向弱势方推移，弱势方给身体反应）→ 反推（写清触发动作）→ 洞穿 → 战果`

禁止两条光带僵持不动、对波后毫发无损。

### 护盾与护体

写明发生器或光膜来源与覆盖扇区；受击先凹陷或涟漪，负荷扩散（裂纹、告警、闪烁），**破裂只发生在累积受击之后**，破裂后果延续到结尾。

### 身法与位移

御剑、踏空、残影、推进器、磁力靴、缆索都要给可见来源。**残像与速度线是运动余迹，不是新增实体**——残影 2–3 道快速淡出，不变成分身。

### 特效分层

- **核心特效**（光爆、剑气、火花、能量波纹）绑定命中瞬间；**辅助特效**（动态模糊、残像、速度线、衣发翻飞、粒子）绑定运动过程。
- 特效不长时间遮住主体轮廓、肢体衔接和接触点；给光效消散时间，不全屏长亮。
- 技能余波只留焦黑裂纹与碎屑，**禁止地面残留发光法阵圈或彩色光环**（外部来源标注为实测）。
- 能量染色天空不超过 1 秒，不改变环境底色。

### 色彩纪律

一场战斗限定一套对立色系（如主角青蓝对敌方暗红），技能形态与角色性格匹配；辅助色少量且不改变主视觉。**禁止每技能一色的彩虹轮播。**

## 六、动作容量与耗时成本

**时间戳是输出，不是输入。**顺序是：列波段 → 波段内列动作 → 查下表求和 → 对照总时长 → 超预算按规则删减。

实时速度下（约 24fps 观感）的最小耗时估值，复杂动作取上限：

| 动作 | 耗时（秒） |
| --- | --- |
| 表情或眼神反应、短暂对峙微反应 | 0.3–0.8 |
| 单次直拳／斩击／点射（含发力与收势） | 0.4–0.8 |
| 含步法接近的一次打击 | 1.0–1.5 |
| 一次完整兵器交锋（出招 → 格挡 → 分离复位） | 1.5–2.5 |
| 反馈链（格挡→偏转→闪避→反攻，或攻击→卸力→变向→追击） | 1.5–2.5 |
| 冲刺接敌（约 5–10 米） | 1.0–1.5 |
| 蹬地起跳到落地缓冲 | 1.5–2.5 |
| 腾空下劈＋格挡＋震退 | 2.0–3.0 |
| 坠落或俯冲穿过一个区域 | 2.0–4.0 |
| 区域转换（含遮挡转场） | 1.0–2.0 |
| 能力或武器系统完整生命周期 | 2.0–4.0 |
| 对波或角力（蓄力→相遇→拉锯→反推→结果） | 4.0–7.0 |
| 胜负手全过程（脱手／破防／倒地／系统失效） | 2.0–3.0 |
| 收束（后拉／落定／结果确认） | 1.5–3.0 |
| 大远景或航拍建立 | 2.0–4.0 |

排程规则：

- **每秒主要动作不超过 3 个**；每 5 秒主要交换不超过 1 个，可附带 1 个顺势动作。
- 决胜波段前后各留至少 1 秒读结果；时间戳连续、不重叠、不遗漏，**结束时间等于总时长**。
- 超预算时按顺序删减：**删空挥与重复交换 → 合并形态相同的波段 → 减区域 → 缩小技能规模**。禁止压缩单个动作的物理时间——不许 3 秒塞下俯冲＋穿障＋落地＋决胜。
- 张弛是排程的结果，不是形容词：标出全片最低势点与决胜点，两点之间必须有可感知的速度、景别或力度对比。高速片用动作密度与景别切换制造呼吸，不靠慢动作。

## 七、环境参战与破坏分级

环境是力量标尺。破坏随波段升级、不提前透支，残骸持续保留到结尾：

1. **微动**：衣发、落叶、积水、灯火、尘雾被气劲吹动。
2. **表面伤**：脚下裂纹、踏碎石台、表面斩痕、甲板凹陷。
3. **局部断裂**：斩波断柱、掩体碎裂、栏杆崩落、管线喷泄。
4. **结构塌陷**：整段桥面或楼板坍塌、巨石崩落、墙体洞开。
5. **地形改变**：冲击波环形扩散改变整片地形、云海或水面被冲开、潮源崩塌；**只用于终局**。

**破坏方向服从受力方向**：人向右飞，碎屑、尘浪、镜头运动主方向一致；垂直重击地面下陷、裂纹放射；横扫让物体横向翻滚。

## 八、声音层

按五层写，不要只列几个拟声词：

**现场底噪**（风、雨、雷、云海、舱体共振、无线电底噪）→ **发力与运动**（衣料、脚步、呼喝、剑鸣、伺服、推进）→ **接触材质与系统声**（金属、闷响、碎裂、法术嗡鸣、供能、报警）→ **余势／落地／散热**（滚落、坠渊、余振、冷却排气）→ **音乐起伏**。

- 对波或决胜前音乐收束（可近乎静音），反推或命中时爆发，胜负落定后收住音乐，留环境声与喘息。
- **默认无对白、无字幕、无战吼、无技能名**；发力呼喝属于动作音，不算法台词。用户指定对白、原声、无 BGM 或全静音时完整覆盖默认。
- 拟声词（CLANG、SWOOSH、CRUNCH）只作辅助，中文自然语言为主；没听到音频不假称解析了 BPM。

## 九、群体战与对轰

### 群体战的密度

无论景别，**每个镜头的前景、中景、后景都要有成排单位**：前景有扑到近前受冲的个体，中景潮线持续推进，后景的地面或道路被成片铺满。技能打出的空缺只允许存在一到两拍，随后由后排踏着同袍重新填满。

"远景有潮、近景空无一物"，或动作镜头里只剩两三只敌人，均视为失败，必须在该镜的句子里补写密度。**波次密度只增不减**；中段安排规模最大的一次奇观；终局必须改变战场地形或潮源，不允许普通球形爆炸收尾。

一轮的五拍：`发起手段 → 爆发 → 群体受冲出现密度空缺 → 反扑与一次近失 → 发起方位移到新位置`

### 对称对轰是高风险图式

四条强制（外部来源标注为实测）：

1. **禁止双方同高度、静止、特效墙对墙的持续相持**——模型会拍成连续数秒相同的壁纸构图。对轰必须高低错位或角度错位，至少一方在位移中施法。
2. 两构造相撞后 **1.5 秒内**按"构造裂纹 → 交界推移 → 一方构造碎裂 → 胜者构造触及败者身体"的有序微拍写完，不许停在相持状态。
3. **大型构造（龙、凤、兽、浪）始终在施法者体外、朝向对手**；施法者不得被自己的构造包裹，护体只留贴身薄层。每个构造在同一句内写明归属与目标。
4. 不允许全屏铺满的峰值：相撞爆光单次 ≤1 秒并在句内写死时长，光源方向与两人轮廓位置写明，禁止只写"铺满画面"。

## 十、常见失败与修复

| 表现 | 提示词中的可能原因 | 具体修法 |
| --- | --- | --- |
| 动作很多但不燃 | 每招同样力度，对手像靶子；没有回合劣势 | 减招，设置招架或反制，安排一次明确失势，再突出一次决定性交锋 |
| 打空却有人倒飞 | 攻击结果含糊；效果先于接触 | 明确命中、格挡或落空，补上力的到达与身体反应 |
| 镜头快但看不清 | 同时多种运镜，整屏模糊遮挡 | 每拍保留一个主运镜，接触前减速，主体保持清晰 |
| 身体像橡皮 | 缺少支撑、距离、关节和恢复 | 写出落脚、转体和收势；减少同时发生的肢体任务 |
| 技能像贴画或 LED 灯带 | 只有"释放蓝光"，没有积聚与衰减 | 补六步生命周期：写能量从哪来、沿什么走、碰到什么、如何散 |
| 对波像两条霓虹灯 | 没有交界线进退和身体反应 | 写交界线推移方向、弱势方犁地颤抖、反推的触发动作与结果 |
| 特效糊成一团 | 发力、命中、爆炸同时开始；两色以上技能混战 | 限定一套色彩谱系；分清释放、传播、接触、消散；压低特效覆盖面积 |
| 角色全程在天上飞 | 身法无支点 | 给每个腾空写支点与落点 |
| 宏大场景像背景板 | 锚点只在开场出现，环境不参战 | 每镜保留 1–2 个锚点；让斩波、气劲、坠落物改变环境 |
| 分镜像重开一局 | 切镜后站位重置、伤损消失 | 每镜写明结束状态，下镜从该状态接起 |
| 一镜到底变蒙太奇 | 出现切镜词，或景别跳变无路径 | 把切镜改为连续移动并给移动时间；无法兼得时明确改用分镜剪辑 |
| 慢动作太多像摆拍 | 每击凝滞，蓄力过长 | 全片升格与冲击帧限次，其余流畅实时 |
| 技能像彩虹轮播 | 只罗列不排序，每技能换一种颜色 | 30 秒选定 3–4 种加一个终局，固定先后；主色统一 |
| 魔潮像背景板 | 敌群只在远处飘、不反击、不爆散 | 写明涌入方向与密度变化、每轮反扑与一次近失、击中后的流体爆散与密度空缺 |
| 割草像站桩播片 | 主角原地连续挥手，瞬移没有位移 | 每次施法后瞬移或折返改变机位高度与方位，写清起止位置 |
| 高速剑术像轮流演招 | 只有攻击没有即时反馈，双方各打各的 | 以反馈链为单位，每击同拍或下一拍必长出对方反应 |
| 敌人像陪练木桩 | 对手只防守不进攻 | 给对手等量的主动进攻、追击、反击与闪避，用角度得失推动交换 |
| 跨区域像换了个世界 | 区域间无路径无遮挡 | 写带时间的空间路线与每段遮挡物，俯冲时看见开场地标 |
| 高速段人物糊成残影 | 镜头与主体同速失控、特效遮人 | 全景中景为主、每拍一个主运镜，主体保持清晰，用背景动态模糊表现速度 |
| 末段事件塞爆 | 3 秒内俯冲＋交剑＋穿障＋落地＋重战＋决胜 | 按成本表拆波段；终局只留连段加一次胜负手 |
| 穿云或穿水变成漩涡、传送门 | 只写"撕开云层、环形空洞、到达云层之上" | 按介质层三段式重写；禁涡眼、对称图案、持续空洞 |
| 不同需求产出套路雷同 | 套固定区域序列与时间表 | 回到设定卡重推：波段、区域、结尾必须由用户剧情推出 |
| 技能过后地面留一圈红或紫光环 | 余波被拍成发光法阵，与下一个技能视觉雷同 | 余波只写焦黑裂纹、碎屑与渐散尘烟，不写持续发光圈 |

诊断时先引用用户文本中的实际问题，再选择修法。**没有原文或生成结果，不把这些通用可能性冒充已经观察到的故障。**
