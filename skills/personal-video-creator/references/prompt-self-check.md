# 提示词自检：逐段推演、修正与复查

用于视频提示词初稿完成后、交付之前。完整新稿从开场推演到结尾；局部改稿检查受影响的段落及其前后衔接，不无故重做其余设计。单镜短片也按动作阶段检查，不必拆出多个镜头或建立复杂表格。

## 按稿件实际写出的内容推演

先核对用户指定的目标、素材职责、时长、关键台词及结尾。然后按时间顺序阅读初稿，依据稿件已有的画面和声音判断下一步能否发生；不要用作者脑中未写出的背景替漏洞补理由。

每段只追踪与事件有关的内容：谁或什么对象在哪里、朝向哪里，人物与观众分别知道什么，手部占用与物品持有者，门窗或材料等关键状态，本段改变了什么，下一段怎样接续。较复杂或分段生成的作品可作简短工作记录；纯产品、舞蹈、过程或界面只追踪对应主体与状态，不添加无关人物心理。

## 找具体问题

| 检查项 | 判断依据与修复方向 |
| --- | --- |
| 剧情因果与人物判断 | 行动有没有当前情境支持的动机或触发？人物能否获得作出判断所需的信息？反转有没有可回溯的依据？发现缺口时补必要的可见线索或调整行动，不靠解释性旁白替代缺失事件。纯展示、舞蹈或界面不强加剧情；荒诞、奇幻按本片已建立的规则检查，不把有意夸张改成写实。 |
| 空间与动作可执行性 | 起点、路线、终点、距离与障碍是否相容？手部、支撑、重心和持机条件是否允许这些动作同时发生？接触有没有对象和结果？例如门未打开却要求穿过，或自拍手与另一只持物手同时腾出做双手动作，需要调整动作或拍法。 |
| 跨段与跨镜连续性 | 身份、服装、数量、位置、朝向、道具持有者、开合、损坏等是否接续？变化有没有发生过程或明确的省略依据？刚放下手机后又使用它，要交代重新拿起或合理时间跳跃。换场重新建立该段状态；交叉剪辑接各自事件线；有意换装、变形或跳时不误判为穿帮。 |
| 时间与表演容量 | 按当前语气估读对白，并推演移动、操作、理解和回应所需的时间。区分可并行与必须先后完成的动作，检查起步、接触、回收和收尾是否被挤掉。容不下时删重复或调整分配，保留关键触发与后果；固定时长和逐字台词确实冲突时明确指出，不偷偷加时或删词。 |
| 观众实际能看见和听见什么 | 当前机位、景别、遮挡、景深与声音距离能否传达关键证据？远景要求辨认微表情、背对镜头却要求同时看清正脸、揭晓前已露出答案，都要调整。笑点、误会解除或产品卖点应由成片可见可听的内容成立，不能只存在于写作说明中。 |
| 要求冲突与生成复杂度 | 检查素材与文字、全局设定与逐镜描述是否冲突，例如一镜到底又要求硬切、固定机位又要求摄影机绕拍。留意同一短段叠加多人交错、复杂接触、快速运镜、精确文字与细微表情的情况；根据核心看点简化非必要要求、调整构图或拆分动作。复杂不等于必然失败，不统一禁用多人、长镜头或动作戏。 |

有舞蹈、音乐、产品、过程或界面目标时，结合[共用写法的类型检查](video-core.md#按类型检查结果)及当前模板检查。例如舞蹈重点看动作路径、承重、回收、取景和实际音乐依据；界面重点看触发、反馈与选中状态。不得编造已完成的音频分析或素材绑定。

使用冲击帧、闪白、反相或闪黑时，再按[动作视觉重音](impact-frames.md)检查：效果对应哪次可辨认的事件，遮挡前是否已交代必要接触，变化何时结束，恢复后人物、武器、方向与后果是否连续。先暂时去掉效果推演动作链，不能用闪帧掩盖未命中、瞬移或缺少受力反应，也不能用全局漫画风覆盖本应短暂出现的处理。

## 修正后再复查

发现问题时，在工作记录中明确“哪一段、什么矛盾、造成什么影响、改哪里”，并实际改入正文。优先解决会让事件无法发生、关键信息无法理解、状态自相矛盾或违背用户明确要求的问题，再处理影响本片看点的其他瑕疵；不为无关细节扩写整稿。

尽量保留有效的创意与观看效果，修改有问题的实现方式。例如关键证据藏在门后但一镜到底无法揭示，可调整人物走位或摄影路线；允许切镜时也可改用明确的切镜，而不是直接删掉揭晓。

修正后重新推演受影响的前后段及同一事件线的后续状态，再核对全片时长、终点和全局要求。若又发现矛盾，继续修正并复查；检查结束以当前稿没有已发现而未处理的实质冲突为准，不为凑轮数反复润色。不可能兼容的用户硬性要求或决定性信息缺失，应在正文外说明具体冲突或所需信息，不声称已经通过。

## 交付与验证边界

通常只交付修正后的完整提示词，不附长检查表，也不把“请自检”“禁止穿帮”当作交给视频模型解决的指令。将本片必要的预防措施落成具体画面、动作与衔接，避免在末尾堆叠通用禁令。

用户要求自检报告时，简要列出实际发现的问题、已做修改和仍待成片核对的项目；没有发现问题就如实说明，不制造问题或声称零瑕疵。

文本自检只能排查稿件中的设计缺口与冲突。身份漂移、手部变形、漏执行动作、字幕和配音偏差等仍需拿到成片后按[反馈流程](feedback.md)核对。未经实际比较，不报告瑕疵率下降或把本流程记成已验证成功的方法。
