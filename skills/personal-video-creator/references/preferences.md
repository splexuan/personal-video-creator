# 个人偏好

以下是当前会话中用户明确表达或认可的偏好。本次指令可以覆盖，不把未提及的习惯推断成要求。

| 偏好 | 来源与适用范围 |
| --- | --- |
| 常用即梦 / Seedance，提示词以中文交付 | 用户选择的平台；未指定模型版本，不预设版本能力或固定时长上限 |
| 常用 9:16 竖屏、电影感写实 | 已有生活情景案例的方向；用户指定其他画幅、风格时跟随本次要求 |
| 角色由上传的参考图绑定，支持任意角色多角度参考 | 用户希望角色三视图加准备好的提示词即可用于生成；保留身份，按剧情改变服装、姿态与神情 |
| 使用七个固定名称的模块整理完整提示词 | 用户指定【角色绑定】【服装】【视角与摄影】【场景】【声音】【镜头】【执行要求】 |
| 提示词要细致，尤其写清情绪和表情过程 | 用户认可换装案例的情绪表情；《明天》也得到总体正面反馈 |
| 创意需要变化，避免反复使用同一种模式 | 用户明确说同一种模式会看腻；变化事件机制、关系、叙事视角与结尾，不只更换服装或台词 |
| 节奏按故事选，不拖沓 | 用户将《狗打的》从十五秒改为十秒；《明天》的十五秒得到正面反馈，不能推广为全片统一十秒 |
| 用满意成片和实际最终提示词继续改进指南 | 用户明确授权这一学习方式；归档时注明反馈程度，不推断所有细节均已实现 |
| 用“生活情景”称呼这类创作，技能可逐步扩展为个人视频指南 | 用户明确不希望叫“女仆换装模板”，之后要求升级为个人技能 |

## 非默认限制

没有固定女主性别、衣服、发型、第一人称机位、反击结尾、音乐禁用或全部无字幕的个人要求。已有案例中的具体选择只属于对应短片。

## 方法来源

七模块及创作方法整理自本会话的模板迭代、用户提供的最终提示词和反馈。此前曾参考“小胖”相关方法，但原始女仆换装提示词由会话直接创作，不能声称它是完整调用“小胖”技能生成的。当前技能独立维护，不依赖或改写其他技能。
