## 形式与设计

规划 30.3 秒、16:9、真人电影级写实、手持摄影，14 个镜头分三段：

- 第一段（0—8 秒）羞辱：男性在楼梯上从背后打女性后脑勺，她撞上扶手失衡，他得意走开，她起身追。
- 第二段（8—18.2 秒）追逐与嘲讽：她冲到站台，车门关闭，他隔着玻璃做嘲讽手势，她冷脸相对。
- 第三段（18.2—30.3 秒）爆发与制服：她一拳击碎玻璃门，把男性拖出车厢、摔在站台地板上，再甩撞瓷砖墙，最后凑近说“别胡闹。”

全片只有两句字幕：“你在开玩笑吗？”与“别胡闹。”，用能量弧线（羞辱 → 追逐 → 嘲讽紧张 → 爆发 → 制服 → 威胁）代替对白推进。

值得保留的设计：

1. **复仇靠量级反转，不靠对白。** 前段把屈辱写足（背后打头、隔着玻璃被嘲），后段的物理压制才有落差；台词只留最后一句收尾。
2. **一件道具承担三个阶段。** 玻璃站台门先开后关，再被击碎，同一个分隔物完成“错过—被隔开—打破”，不必换景。
3. **每段末态接下一段起态。** 楼梯底 → 站台 → 车门前 → 站台地板，路线连续可通行，位置不跳变。
4. **字幕只标关键句**，把过程交给动作和摄影。

## 下一稿可检查的点

- 参考图与文字服装冲突时，除显式声明外仍要预留复核步骤：把服装核对放到关键镜头，不只依赖一句总声明。

- 字数少不等于不会错：本例收尾句只有四个字，仍多出一个“笑”字。核对时不能只防“漏字”，也要防“多字”和“认错字”。
- 生成端对画面文字与配音会各自出错，核对要放在拿到生成产物之后、后期加工之前，不指望后期兜底。
- 需要精确落点时，按手上这一版的时长重新定位，不沿用规划时间；核对任何偏差前，先确认这一版有没有经过后期加工。
