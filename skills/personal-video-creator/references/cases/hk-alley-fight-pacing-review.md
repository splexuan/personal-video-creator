# 案例：香港动作片后巷打斗（节奏失败复盘）

**日期**：2026-10-12
**类型**：动作／打斗（写实徒手＋环境道具）
**规格**：30 秒，16:9，24fps，1280×720，带音轨
**证据状态**：成片已实际查看（含逐帧量化与关键帧抽检）；**用户判定失败**——画面质感被认可，但"剧情太垃圾、打斗不流畅、节奏不紧凑、好像减速了一样、站在原地等时间、观感太差"
**归档角色**：**失败案例，不作成功参考**。用于识别"动作密度不足"这一类问题的诊断方法。

---

## 一、反馈原文

> 画面其实不错很有质感，但剧情太垃圾了，打斗不流畅，节奏不紧凑，好像减速了一样，站在原地等时间，观感太差

**拆解**：画面／质感 = 通过；**剧情、流畅度、节奏 = 不通过**。注意这是**一条分层的反馈**——同一个稿子里，美术层成功、节奏层失败。这说明问题不在人物、场景与质感描述，而在动作的组织方式。

---

## 二、成片实测

用 `scripts/motion-audit.py` 得到的量化结果（运动能量＝相邻帧差分图平均灰度，0–255）：

| 指标 | 实测值 |
| --- | --- |
| 全片运动能量 | 均值 4.51，中位数 4.42，P10 0.67，P90 8.28 |
| **最长近静止区间** | **5.29 秒（19.42–24.67 秒）** |
| 该区间落在哪 | 正是稿件写明的**全片决胜点**（决胜一击那一整段） |
| **运动最高点** | **14.96 秒 —— 一个转场切换点**，不是任何决胜动作 |
| 次高与第三 | 25.0 秒（床单掠过）、24.0 秒（镜头切换） |
| 帧复制检查 | mpdecimate 保留 721 / 总 721 帧 → **零重复帧** |
| 场景切换点 | 10.0 / 14.96 / 19.38 / 24.75 秒 → 六段结构被遵守 |

**三个读数说明的事**

1. **5.29 秒死区落在决胜段** → 重音完全配反。该动的地方最静。
2. **最高点是转场** → 全片唯一"动得厉害"的瞬间是镜头切换，不是动作。观众记住的"动"是剪辑带来的，不是打斗带来的。
3. **零重复帧** → 不是播放端减速、不是补帧问题，**是内容本身慢**。这一点很重要：用户的主观感受是"好像减速了"，但实际是画面里的人真的没在动。

## 三、关键帧核对

| 时间 | 画面实际内容 |
| --- | --- |
| 3.0 秒 | 主角捂腹、跪在积水里，双手握拳，**静止**（对应 2–4 秒近静止区间，均值 0.68–1.18） |
| 6.0 秒 | 主角双手把红胶凳举过头顶，对手挥拳——本片少数密度达标的帧 |
| 17.0 秒 | 对手单手举着黑铁锅挥击，主角背贴砖墙——构图和质感好，动作清楚 |
| **21.0 / 23.0 秒** | **主角双手横持一条鱼、对手直立站在巷中——两个时间点的画面几乎一致，这个姿态持续了 5 秒** |
| 25.0 秒 | 一条白床单掠过画面，全片运动最高点 |

**决定性的一帧是 21 秒**：稿件原文写的是"伸手摸到那条鱼，双手抱住鱼身当棍，抡圆甩出去"，成片只实现了"**双手抱住鱼身**"这一半，并把这个状态保持住。**生成端把"持物"这个名词性描述渲染成了一个静态姿态。**

---

## 四、根因（全部出在稿件）

| # | 根因 | 稿件原文证据 |
| --- | --- | --- |
| 1 | **把动作写成了名词**——持物只写状态、不给位移轨迹 | "双手抱住鱼身当棍"；生成端实现了"抱住"，没实现"甩出去" |
| 2 | **动作密度只有 0.2 单元/秒** | 30 秒只安排了 6 个动作事件，一段 5 秒一件事 |
| 3 | **主动写了三处"停"** | 段 A"单膝跪进积水……抬头先看彪哥的手、再看小弟的棍，脸上是'完蛋了'的表情"；段 C"两个人顶着在积水里横着小半步"；段 E"彪哥先愣住、再疼得单脚跳……阿全自己也愣了半拍" |
| 4 | **分段模板让每段动量归零** | 六字段承接状态里每一段都填了"动量近零／收势"，等于逐段下达"结尾停下来"的指令 |
| 5 | **"极短停顿"被画成了 5 秒静止** | 原文"画面极短地凝住约 0.2 秒"——生成端不理解 0.2 秒，按"静态"画 |

根因 3 的三处与实测的三个运动低谷（2–4 秒、12–15 秒、19–24 秒）**一一对应**。

---

## 五、修正稿做法（可复用）

修正稿《滚汤》把机制换成"**一只不能放下的锅**"，并把五条整改写进正文：

1. 密度写在稿子最前面：30 秒 95 个动作单元（写作量 3.2 单元/秒，目标落地 1.8–2.2）。
2. 每个持物动作都带位移轨迹（锅从头顶左侧划弧到右手、锅从腰侧举过头顶、锅从空中被单手托住）。
3. 全稿检索"停／愣／站定／保持／凝住／抬头看"＝0 处；五处痛感全部写成动作中的副动作。
4. 每段承接动量均为非零并写明方向；十段切点全部落在动作进行到 60–80% 的那一帧。
5. 唯一的节奏低谷（脱手飞起）改写成"锅的抛物线 ＋ 空出手连打三下"，是运动不是静止。

**机制层面的选择**：弃用"道具接力"（一件一件用，天然产生"用完一件停一下"），改用"手里有件不能放下的东西"——手被占用，每一击都要重新平衡，密度由故事条件供给，而不是靠写作技巧硬堆。

---

## 六、验证状态

- **待核对**：修正稿尚未生成，五条整改是否真的能让死区消失，需按新成片的运动能量实测确认。判据是——任何连续 2 秒区间的运动能量若仍持续低于 1.5，即判定整改不足。
- **已确认可迁移**：本案例的四条根因（持物写成状态、密度过低、主动写停、分段动量归零）与量化诊断方法，已提炼进[动作密度与节奏](../pacing.md)，不依赖本片的重测结果。
- 本案例的分层结论保留：**美术层通过、节奏层不通过**。修正稿沿用原人物与后巷资产，不推翻已被认可的画面部分。
