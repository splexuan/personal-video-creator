# 多类型视频的共用写法

与[类型索引](video-types.md)及本次所选模板一起使用。生活情景是一种内容类型；广告、MV、界面动效等有各自的视觉目标，不预设都需要人物关系、误会或对白。

## 先确定视频要完成什么

明确主体、观众应看到的变化和最后的画面。剧情看选择，广告看产品，时装看造型，MV 看表演与音乐，流程看阶段结果，界面看交互状态。用户给出既有提示词时，先保留其目标与结构，再调整需要修改的部分。

画幅、时长、写实程度、对白与音乐按本片选择。已有的 9:16、电影感写实是生活情景常用方向；游戏与界面可因布局采用横屏，动画和 DV 采用对应画风。未指定但能判断时选合适方案并简短说明，不为例行选择停止创作。

## 按当前任务选择结构

先确定本片需要表达和约束什么，再选择字段。用户已提供的有效结构优先；有明确平台输出格式时按实际格式转译。分类模板只给参考组织方式，可以增删、合并、改名与重排，也可以用带时间的连续描述。模块数不用于判断质量。

| 类型举例 | 适合的组织方向 |
| --- | --- |
| 生活情景、剧情 | 人物关系、造型与道具、空间、表演、声音、分镜；早期七模块适合时可保留 |
| 纯产品广告 | 产品与素材、展示目标、视觉与摄影、镜头脚本、声音和品牌文字、产品连续性 |
| 舞蹈或音乐 MV | 表演者与造型、音乐依据、编舞或视觉表演、舞台与摄影、时间线、同步与连续性 |
| 动物互动 | 动物与对象、环境及视角、行为时间线、声音、关键连续性；配饰仅在实际需要时写入 |
| 制作与改造 | 对象和目标、固定基准与材料、阶段过程、摄影、声音与最终状态 |
| 游戏与界面 | 角色或界面素材、布局和任务、交互反馈、操作时间线、声音、状态约束 |

名字应当直接说明内容：产品用产品字段，界面用布局与交互字段。无需为没有造型设计的片子保留【服装】，也无需把界面素材写成角色绑定。很短的单一动作可以在一段时间线中交代素材、摄影和声音；较复杂的多镜故事再拆开说明。

要保留的是关键内容：实际素材归属与固定特征、可见变化及时间、摄影和空间、声音依据、衔接和终点。相关信息可以合写，画风与制作方法放入当前结构的合适位置。删掉无关字段时检查有没有连带丢失必要的材料或连续性要求。

最终稿填写实际内容，删除空栏目、占位符、来源分析、备选项和模板中的创作者说明。来源平台的格式仅在本次确实使用该入口时采用。

## 参考图与状态变化

把身份、衣服、产品外观、场景布局、分镜、风格和音频分别指定到实际素材。未提供素材时用文字设定，不声称已经绑定上传图。角色三视图属于同一身份；分镜图的多格属于镜头顺序，成片重建完整画面。

区分固定特征与允许变化。例如改造过程固定房间结构但改变表面和陈设；换装固定人物身份但改变指定服装；恐怖分身戏明确有两个外貌一致的人，不能把该剧情误删为人物复制。状态变化给出时间与原因，后镜沿用结果。

## 时间与动作容量

先给最重要的信息、动作、反应或定版留时间，再安排其余内容。不要把所有类型压成十秒，也不要把一个代表案例的秒数变成默认。模板段落可合并或拆分，每段只安排能完成的主要变化。

镜头时间连续且总和正确；动作有开始、接触或变化、结果。连续镜头需要真实可通行的路线，蒙太奇与延时允许省略时间但要写明。若分段生成，保留各段末态与下一段起态及真实拼接方式。

## 声音与文字

准确台词标说话者、语言与时间；声音从人物、环境或设备产生。对白需要回应容量，ASMR 需要声源清楚，MV 需要音乐依据。已给音频按实际人声、段落与重拍安排，不从歌名猜出精确 BPM 或秒点；未提供音频时可先写音乐方向与可调整的结构，不声称已完成逐拍同步。

字幕、品牌字标、游戏 HUD 和界面文案按本片需要保留，不能统一禁用文字。指定文字逐字列明，未提供的宣传性能、数据或评价不当作已核实事实生成。

## 按类型检查结果

| 主目标 | 要检查的实际结果 |
| --- | --- |
| 剧情、喜剧、动物、Vlog | 触发与回应是否看懂，人物或动物注意力是否清楚，结尾是否完成事件 |
| 产品、UGC、时装、车辆 | 主体可辨认，结构与造型连续，操作或运动有接触结果，展示重点可见 |
| MV、舞蹈、运动、动作 | 时间依据与动作落点，关键表演可读，重心、接触、回位和结果成立 |
| 奇幻、悬疑 | 规则、信息范围、异常时机与后果保持一致 |
| 美食、制作与改造 | 阶段顺序、材料状态、前后基准与声源对应 |
| 游戏、界面 | 任务、路线、交互反馈、HUD 或布局状态对应，文字内容正确 |

表演、镜头与特效的要求按当前目标使用，避免把“每片都克制”“每片都稳定”“每片都要反转”写成全局限制。新片实际结果按[反馈流程](feedback.md)归档。
