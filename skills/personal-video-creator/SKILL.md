# 个人视频创作指南

把主题与素材写成可用于生成视频的提示词。生活情景只是其中一种类型；其他类型依据已读外部案例形成分类模板。重点是主体连续、具体动作与表演、符合类型的摄影与声音，以及适合目标的节奏。

## 入口与按需阅读

每次先读 [个人偏好](references/preferences.md)，本次用户要求优先。

| 当前任务 | 读取资料 | 交付 |
| --- | --- | --- |
| 想创意、选类型 | [导演设计](references/directing.md)、[类型与模板索引](references/video-types.md)；生活情景再读[生活情景方法](references/life-scenes.md) | 有区别的观看路径、事件机制与结尾；只要创意时不强行展开全文 |
| 写完整提示词、改已有提示词 | [共用写法](references/video-core.md)、索引中对应的一个内容模板；新创作或重做镜头方案读[导演设计](references/directing.md)，按需读画风或制作方法 | 把视觉主意、表演与衔接落实为可复制的完整提示词；小范围修改保留已有设计 |
| 写舞蹈、热舞、手势舞或编舞主导的 MV | [舞蹈导演](references/dance-performance.md)；整支舞设计或重编读[完整编排](references/dance-composition.md)，素材与取景未定读[创作准备](references/dance-preparation.md)，按目标选短版或 MV 模板 | 由 AI 设计有记忆点、节奏、发展、高光与结束关系的完整表演，细化动作和摄影；判断是否准备参考图及其取景，并引导完成下一步 |
| 参考以前满意的效果 | [案例索引](references/case-index.md)，再读相关案例 | 借用有效的表演与叙事方法，另写当前故事 |
| 借鉴外部提示词或参考视频 | [类型索引](references/video-types.md)；生活情景按需读[研读方法](references/external-cases.md) | 提炼当前类型的表演、摄影、动作与状态组织；外部样片和网址不写入技能 |
| 看成片、学习反馈、更新指南 | [反馈与维护](references/feedback.md)及相关案例 | 有依据的评价、必要修改，以及用户已授权范围内的记录更新 |

遇到多类参考素材混用、喜剧笑点安排或逐镜修复时，按需读[外部方法参考](references/external-methods.md)。其中保留来源和适用条件，常规创作不需要联网读取整套外部仓库。

写作或修改视频提示词时，交付前读取并执行[提示词自检](references/prompt-self-check.md)。覆盖所有内容类型，包括舞蹈；完整新稿逐段推演，局部修改检查受影响的段落与前后衔接。只讨论创意或评价成片时，不强行展开完整提示词自检。

设计冲击帧、闪白、反相或闪黑，或修复这些效果的时机与衔接时，读取[动作视觉重音](references/impact-frames.md)，并与当前类型模板、自检配合使用。动作、仙侠与动画可按需要采用，不给普通旅游、风景或其他视频默认添加闪帧。

## 创作流程

1. 从用户材料确定主要目标、主体、变化和结尾，选最合适的内容类型。优先复用已提供的信息；缺少非关键项时按本片需要选择，缺失的素材不虚构已经绑定。
2. 确定观众的观看终点及结束画面，再选能落到构图、动作或声音的视觉主意。按类型安排关键变化与时间；多个创意改变观看路径或事件机制，不只替换角色与服装。
3. 分配实际素材职责，区分固定身份或结构、可变状态及当前构图。安排位置、距离、路线、视线目标和动作起止；人物选择、动物行为、产品操作与界面反馈分别用适合的可见证据表达。
4. 根据观众与主体分别何时知道什么，安排持续观察、摄影运动或切镜。机位看得到关键内容，声音有归属，反应有容量；跨镜接起态与末态，换场与交叉剪辑按各段事件重新建立空间和状态。详见[导演设计](references/directing.md)。
5. 根据内容目标、素材和实际生成入口选择最合适的提示词结构。对应模板是起点，可改名、增删、合并或重排字段；需要时也可用连续描述、时间线或平台明确要求的格式。生活情景的七模块是一种可选写法。画风和制作方法放到本片合适的位置，删除空栏目、占位符与创作者说明。
6. 完成初稿后，按[提示词自检](references/prompt-self-check.md)从开场到结尾逐段推演，核对因果、空间与动作、跨镜状态、表演容量、信息可见性和复杂要求。发现具体问题就修改正文，再复查受影响的前后段及全片目标、时长和指令一致性；不能用一句“已检查”代替修正。
7. 完成“初稿 → 逐段推演 → 修正 → 复查 → 交付”后，直接给出所需提示词。自检记录通常不进入生成用正文；未解决且影响执行的冲突须在正文外说明。用户要求比较、设计稿或自检报告时再展示相关内容。用户明确满意并提供实际使用的最终稿时，再按反馈流程归档；文本自检通过不等于成片已经验证。

## 创作与维护边界

- 时长、画幅、画风、镜头数量、视角、表演强度、音乐与结尾服务当前目标，不固定套用某个旧案例。
- 支持角色参考与文字创作；缺少舞蹈参考时给取景建议和参考图提示词。用户明确要求或已授权生成参考图时使用可用生图能力，生成后检查并继续；仅写提示词或修改指南时不自行生图。不把文字创作扩展为自动消费视频生成额度、上传发布或修改其他技能。
- 《明天》的长停顿、《狗打的》的十秒节奏、换装案例的羞恼反击、复仇喜剧案例的三十秒三段式均有特定用途，不作为所有短片的默认剧情。
- 更新时区分个人偏好、单个案例经验和成片已观察事实。保留实际最终提示词，并记录证据来自用户反馈还是直接看片。
- 新增或扩展外部方法参考时，按[来源维护规则](references/external-methods.md#新参考登记与同步)同次更新技能来源表和仓库 README 的“外部方法参考”表，注明实际已读范围、采用方法、入口与验证状态；README 的来源名称附已核对的原始链接。
- 外部样片只作参考分析，技能仅保留可复用方法，不收录样片资料、账号、视频文件名、视频地址或外部网址。用户自己的最终提示词与已认可案例继续保留；新故事效果按实际反馈积累。
- 按本次类型读取对应模板，避免每次加载全部模板。新增类型仍以实际用途和具体案例为依据；用户要求的结构与范围优先。
