# 个人视频创作指南

把用户的一句话想法发展成有具体视觉设计、完整观看过程和细致分镜的创作方案，再写成生成用提示词。**先发散出几个机制不同的候选并择优，再把选中的做实**——细节写得再细，也不能救一个平庸的机制。**有题材对口的模板就用模板，写正文前先取一条题材最接近的外部样本当锚点，不凭通用的视频生成知识自创结构。**主动承担场景选择、摄影、表演、声音和节奏设计，不把这些工作留给用户补齐。生活情景只是其中一种类型；按当前题材调用已提炼的参考方法，兼顾画面美感与主体连续性。

每次先读 [个人偏好](references/preferences.md)，本次用户要求优先。

遇到多类参考素材混用、喜剧笑点安排或逐镜修复时，按需读[外部方法参考](references/external-methods.md)。其中保留来源和适用条件，常规创作不需要联网读取整套外部仓库。

写作或修改视频提示词时，交付前读取并执行[提示词自检](references/prompt-self-check.md)。覆盖所有内容类型，包括舞蹈；完整新稿逐段推演，局部修改检查受影响的段落与前后衔接。只讨论创意或评价成片时，不强行展开完整提示词自检。

设计冲击帧、闪白、反相或闪黑，或修复这些效果的时机与衔接时，读取[动作视觉重音](references/impact-frames.md)，并与当前类型模板、自检配合使用。动作、仙侠与动画可按需要采用，不给普通旅游、风景或其他视频默认添加闪帧。

**凡是"本该一直在动"的片子（打斗、追逐、群战、冲撞、跑酷），写正文前先读[动作密度与节奏](references/pacing.md)并按它定动作单元总数与幅度。** 这一类片子有两道独立的关，都可能单独失败：

- **密度关（"够不够快"）**：成片看起来像减速、人物站在原地等时间。根因永远在稿子的密度上。三条最容易犯的错：把持物写成"抱住／举起"这类**状态**而不给位移轨迹；为了让分段能拼接而让每段动量归零；用"极短停顿／凝住"表达节奏上的顿（生成端会把它画成静态，实测中被画成了 5 秒的静止）。节奏的顿一律改写成"换一种运动"。
- **幅度关（"像不像在打"）**：成片一直在动、没有死区，但看着不像打斗。根因是动作**幅度**太小——人多半在原地高频摆手脚，没有倒地、没有大位移、没有第二个人同时在动。修法是把对手放倒（每 5 秒至少一次）、让两个以上对手同时在场、改成抓握式的持续接触、把机位压到腰以下。实测对照见 pacing.md 第三节。

**不要用快剪救节奏**——参照样本证明打斗感来自幅度与同时性，不来自切镜频率；切镜只会让运动最高点落在剪切那一帧上，那是剪辑在动，不是人在动。幅度两关都过之后，还要看受力对不对（[动作与受力语法](references/action-craft.md)）。

确认平台能力时读取[平台口径与已核事实](references/platform-notes.md)：素材上限与推荐区间、参考素材的指代写法、负向约束的位置与写法、时间戳、声音与字幕的分隔符、提示词的官方结构与顺序、时长与分辨率。该册只记平台规格与语法，并逐条标注证据等级（官方 / 多源一致 / 二手待核）；未被核对的规格以实际入口为准，不把某一入口的限制写成平台能力。

## 创作流程

1. 从用户材料确定主要目标、主体、变化和结尾，选最合适的内容类型。想法模糊、只有一个方向或用户明确要创意时，先按[创意发散](references/creative-divergence.md)比较几个机制不同的候选，选定机制后再往下做。优先复用已提供的信息；缺少非关键项时按本片需要选择，缺失的素材不虚构已经绑定。
2. 确定观众的观看终点及结束画面，再选能落到构图、动作或声音的视觉主意。**写正文前先取参照**：按本次题材从[外部提示词库](references/external-library/index.md)挑一条最接近的 ★ 样本当锚点，并按[模板结构规则](references/external-library/structural-rules.md)选对口结构——有对口模板就用模板，不凭通用的视频生成知识自创结构。普通新创作也调用已提炼的相关参考方法，说明其在当前稿中改变了哪项摄影、表演或节奏决定；这个判断通常留在内部，不把来源分析塞进生成正文。选中的主意要能说出强度来源（意外、反差、精确时机或唯一性，见[画面强度](references/cinematography.md#画面强度)），说不出来就回到上一步换机制，不要靠加细节或形容词去补。按类型安排关键变化与时间。
3. 分配实际素材职责，区分固定身份或结构、可变状态及当前构图。安排位置、距离、路线、视线目标和动作起止；人物选择、动物行为、产品操作与界面反馈分别用适合的可见证据表达。**动作类片子在这一步先把动作单元总数定下来**：按[动作密度与节奏](references/pacing.md)的目标落地密度乘两到三倍得到写作量，写完后数一遍核对；数量不够就补动作，不靠形容词加力。**同时按同册第三节点幅度**：全片至少 6 个单元的位移达到半个画面高度、每 5 秒至少一次"对手从站立变倒地"、画面里始终有两名以上对手同时在动、机位不高于人物腰部。
4. 根据观众与主体分别何时知道什么，安排持续观察、摄影运动或切镜。把关键画面的视觉中心、空间层次、机位、光线作用和运动起落写具体，按[摄影与画面设计](references/cinematography.md)检查整段观看体验。机位看得到关键内容，声音有归属，反应有容量；跨镜接起态与末态，换场与交叉剪辑按各段事件重新建立空间和状态。详见[导演设计](references/directing.md)。
5. 根据内容目标、素材和实际生成入口选择最合适的提示词结构。对应模板是起点，可改名、增删、合并或重排字段；需要时也可用连续描述、时间线或平台明确要求的格式。生活情景的七模块是一种可选写法。画风和制作方法放到本片合适的位置，删除空栏目、占位符与创作者说明。实际用了参考素材时，按[平台口径](references/platform-notes.md)核对素材标签写法、数量区间与约束块位置，标签与实际上传编号一致，没有的素材不写标签。
6. 完成初稿后，按[提示词自检](references/prompt-self-check.md)从开场到结尾逐段推演，同时检查摄影与观看体验、因果、空间与动作、跨镜状态、表演容量、信息可见性和复杂要求。能顺利发生但画面空泛、重复或缺少视觉发展，也要改正文。再复查受影响的前后段及全片目标、时长和指令一致性；不能用一句“已检查”代替修正。
7. 完成“初稿 → 逐段推演 → 修正 → 复查 → 交付”后，直接给出所需提示词。自检记录通常不进入生成用正文；未解决且影响执行的冲突须在正文外说明。用户要求比较、设计稿或自检报告时再展示相关内容。用户明确满意并提供实际使用的最终稿时，再按反馈流程归档；文本自检通过不等于成片已经验证。

## 创作与维护边界

- 时长、画幅、画风、镜头数量、视角、表演强度、音乐与结尾服务当前目标，不固定套用某个旧案例。
- **生成是要花钱的（本机实测约 40 元/次）。**交付动作类长片时把成本顺序写在最前面：直出版是一次生成、分段版按段数次生成，默认先跑直出版，出片后用 `scripts/motion-audit.py` 核对，只在某一段出问题时局部补拍，不整片重来、不两版同跑。稿子要在交付前把已知的翻车项排完（平台硬边界、机位黑名单、密度指标），不靠"先生成一条看看"来试错。
- 支持角色参考与文字创作；缺少舞蹈参考时给取景建议和参考图提示词。用户明确要求或已授权生成参考图时使用可用生图能力，生成后检查并继续；仅写提示词或修改指南时不自行生图。不把文字创作扩展为自动消费视频生成额度、上传发布或修改其他技能。
- 《明天》的长停顿、《狗打的》的十秒节奏、换装案例的羞恼反击、复仇喜剧案例的三十秒三段式均有特定用途，不作为所有短片的默认剧情。反过来，**动作类片子不允许"停"**：《明天》那种长时间停顿的写法只适用于情感戏，写打斗时按[动作密度与节奏](references/pacing.md)检查全稿有没有"停／愣／站定／对峙"。
- 更新时区分个人偏好、单个案例经验和成片已观察事实。保留实际最终提示词，并记录证据来自用户反馈还是直接看片。
- 新增或扩展外部方法参考时，按[来源维护规则](references/external-methods.md#新参考登记与同步)同次更新技能来源表和仓库 README 的“外部方法参考”表，注明实际已读范围、采用方法、入口与验证状态；README 的来源名称附已核对的原始链接。
- 外部提示词原文、题材与证据标注可以收录，供写稿时取用参照；样片视频与音频、账号、原片文件名、视频地址、外部网址、本机素材路径不收录，来源链接只在仓库 README 登记。**外部收录不等于本机已验证**——锚点样本的成功只是原作者的声称或来源的标注。用户自己的最终提示词与已认可案例继续保留；新故事效果按实际反馈积累。
- 平台规格与提示词语法统一记在[平台口径](references/platform-notes.md)，逐条标证据等级，不把单一来源的转述写成平台事实；该册与仓库 README 的来源表同次更新。
- 按本次类型读取对应模板，避免每次加载全部模板。新增类型仍以实际用途和具体案例为依据；用户要求的结构与范围优先。
